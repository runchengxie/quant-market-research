# 风险过滤与实际退出

[English](execution-risk-guards.md)

2024年开发样本中，新增风险过滤避免了正源和中银的买入，在共同减值假设下提高了账户收益；美吉姆仍被困，不能把收益改善理解为成功规避所有退市风险。下一步应冻结规则并验证独立年份。

本试验比较原始小市值基准与增加风险过滤的版本。过滤影响下一次买入与调仓；持仓能否卖出仍由分钟成交规则决定。停牌、一字跌停和参与率限制下未成交的股票继续留在账户中。

原基准已有 ST、历史名称、上市时间和停牌资格过滤。新增试验检查 ST 标记的可得时间，排除上一交易日收盘价低于1元的候选股，并使用已公开的终止上市决定。1元是本次研究参数，需要检验机会成本，不是保证避免退市的规则。所有信号在前一交易日20:02形成，下一交易日09:32开始执行。

原时间线显示：正源和中银的首次买入前收盘价已低于1元；美吉姆买入时仍高于1元，ST 信息尚未生效。美吉姆后来的退出尝试遇到停牌及一字跌停，因此不能把它改写成成功卖出。

候选股票从完整日线股票池重新选择，不能先用全年事后选中的109只限制选股。只有新选择的股票均落在原已审查输入范围内时，才复用其分钟行情、公司行动和复权证据。原始输入逐文件核验，基准目标需精确复现。新增输入或规则变化必须使用新目录，不能续用旧结果。

完整选股日线另存为外部准备输入并计算内容哈希。其原109只股票的数据需与旧准备输入逐行一致。旧基准未保存完整候选池，因此不能追溯证明当时所有未入选股票的历史文件字节完全相同；这一限制保留，不能用清单哈希代替行情内容校验。

终止上市公告源包覆盖本次原输入中的四只2024年退市股票，包括界龙实业。这是样本覆盖，尚不是全市场公告库。仅有发布日期的公告保守映射到随后首个交易日09:00可得，不能把日后摘牌日期或证券名称倒灌成提前预警。

配对试验统一在已知终止决定后采用零估值假设，保留法律股数，不增加现金，不生成卖出成交。风险版本和基准使用相同估值政策，避免把政策变化误当作过滤收益。原有严格运行、减值情景和单来源转让报价情景继续保留。

先比较每日调仓、100万元和1000万元。其余调仓与拆单矩阵尚未完成，本试验不能直接作为实盘容量结论。复核需分别检查买入变化、未成交退出、滞留股数、正常股票机会成本、费用和日净值。

规则是在查看2024年失败样本后提出的，因此2024年是开发样本。即使每次调仓只用当时已知的信息，也不能把全年收益改善称为样本外验证。下一步应冻结规则，再用独立年份和其他市场环境检验。

独立退市板块报价探索仍未取得可严格验证的历史成交收盘价。另一来源的年末价格图只能旁证个别值；交易规则中的每手股数和最小价格单位，也不能替代行情接口量额字段的官方单位说明。现有单来源报价限制继续保留。

## 本次对照结果

2024年242个交易日，每日调仓40只股票；两组均使用终止决定后全额减值的同一假设。以下为账户收益，不是相对指数的超额收益。

| 初始资金 | 原基准收益 | 风险过滤收益 | 差额 |
| --- | ---: | ---: | ---: |
| 100万元 | 4.73% | 12.31% | +7.58个百分点 |
| 1000万元 | 3.60% | 11.10% | +7.50个百分点 |

风险版本未买入正源和中银。美吉姆仍滞留13,900股和138,500股，两种资金规模各有65张卖单零成交。界龙曾买入并卖出，终止决定生效时已无持仓。新增界龙非交易事件使基准多出120条零数量拒绝买入记录；与先前减值基准相比，资金账、持股及实际成交内容一致，生成的订单编号和估值注释不同。

风险版本的全年交易费用分别为8,843.71元、87,073.21元，基准为8,372.04元、82,415.83元。收益改善并非省手续费；它包含买入变化、替代持仓和后续调仓的共同影响，尚未逐项归因。

独立复核重新计算选股顺序、信号与执行时间、现金、持股、权益、费用和日净值，四组均通过；估值事件不产生现金，终止事件后的相关证券没有实际成交。原18组公开结果未改动，九组矩阵仍不完整。上述开发样本结果不能替代独立年份验证或实盘容量测算。

## 复现

在仓库外指定两个新的输出目录。准备脚本不会修改原始输入；任何新增证券超出原分钟证据范围时直接拒绝复用。

```bash
uv run --locked --extra formal --extra duckdb python scripts/prepare_execution_risk_comparison.py \
  --data-root "$QUANT_DATA_ROOT" --base-prepared "$ORIGINAL_PREPARED" \
  --source-packet "$RISK_SOURCE_PACKET" \
  --baseline-output "$BASELINE_OUTPUT" --risk-output "$RISK_OUTPUT"

uv run --locked --extra formal --extra duckdb python scripts/run_execution_cost_minute.py \
  --run-prepared --output "$BASELINE_OUTPUT" --scenario fees_1m --scenario fees_10m
uv run --locked --extra formal --extra duckdb python scripts/run_execution_cost_minute.py \
  --run-prepared --output "$RISK_OUTPUT" --scenario fees_1m --scenario fees_10m
```

配对输入绑定共同估值政策，因此不能额外传入另一套估值参数。仅允许上述两组每日调仓情景，九组矩阵完成标记仍为否。政策、输入或相关实现变化时，必须创建新的目录。
