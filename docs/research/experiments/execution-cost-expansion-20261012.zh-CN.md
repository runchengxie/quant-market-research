# 交易成本扩展：历史盘口、订单流适用性与策略敏感性

[English report](execution-cost-expansion-20261012.md)

本轮完成了十个交易日、306,483条有效双边证券分钟盘口的测量。10万元订单的静态买卖成本中位数为9.27/8.87基点；100万元订单的十档完整覆盖率为62.12%/67.68%。这反映当时盘口的可见深度，不是实盘滑点。

早期数据的优势需要分市场判断。106只共同证券中，2021-01-04的已观测分钟覆盖率为100%，2026-04-16为96.99%；但早期沪市共同样本有成交记录，却未观测到对应委托。深市买卖订单编号候选匹配率为99.68%/99.75%。两期数据均未通过精确事件回放验证。

同时，现有微盘诊断已通过共享执行模拟器完成十八组资金与成本情景。这把成本假设连接到了部分成交、未成交与现金约束，尚不能证明真实策略容量或净超额收益。

## 样本与成本口径

日期在查看成本分布前固定：2021-01-04/15/29、2025-01-02/15/27、2026-04-07/16/24及2026-07-20。历史两个月采用标准化月文件，近期采用原生文件。月份、日期和证券不是概率抽样；1月季节性与年份差异混杂，共同证券还带有存续筛选，不能据此描述全市场长期趋势。

选取沪深股票形态代码前缀、数值代码模37为零的证券。每证券每分钟先取时间最早的记录，同时间按源行号排序，再检查盘口。时段为[09:30,11:30)、[13:00,14:57)。共观测311,395条分钟盘口，剔除4,912条单边盘口，保留306,483条有效双边盘口，覆盖1,317个有效证券日。分钟覆盖的分母是当天已观测证券数乘237，不是历史全部合格股票。

时钟采用明确输入契约：早期`time_ms`为相对09:30的毫秒数，保留午休；近期为`HHMMSSmmm`。竞价和收盘边界探测及选中源记录检查支持该解释，字段改名本身不会转换时钟。价格按分、数量按股解释；选中样本的累计成交金额/成交量/价格尺度检查均落在[0.8,1.2]。这只是尺度检查，不能替代供应商规范或精确金额核对。

成本以当时买卖中间价为基准，包含半价差与吃档成本，不再另加价差。名义规模等于中间价乘分析股数，允许非整手，不是现金预算或真实整手订单。十档深度不足时，完整订单成本留空，不外推；税费、延迟、补单、排队与自身因果冲击均未包含。

按此前20日平均成交额分组，低组100万元买入完整覆盖率为43.56%，高组为77.53%。分位组以可用的全A股日频截面（含北交所）为参照，盘口样本本身不含北交所。成交额乘1000统一为元，前一日流通市值乘10000，波动率用此前收盘价/前收盘价的对数回报。2,481条有效盘口缺少完整成交额或波动率历史，保留在不可用组。重建的日频估值不证明历史发布时点可得；这些分组是描述性结果，没有总体置信区间。

## 订单流能支持什么

共同证券审计保留源顺序及特殊事件，将重复事件、时间倒退、业务序号为零与正序号回退分开统计。两日均有效的证券分钟有23,297对；这个固定配对样本与较宽的共同证券样本分开报告。

| 共同样本记录 | 2021-01-04 | 2026-04-16 |
| --- | ---: | ---: |
| 连续交易委托记录 | 1,506,074 | 6,787,780 |
| 成交／事件记录 | 1,596,501 | 4,189,318 |
| 非正价格事件 | 0 | 715,285 |
| 正价格成交中的时间倒退 | 0 | 64,245 |
| 正价格成交中的正业务序号回退 | 无对应字段 | 22,694 |

早期开盘前委托另有25,785条，与连续交易委托的精确重叠为零。引用查找使用两者的并集，重复和歧义候选键不被悄悄删除。早期查找没有通道字段，近期另用通道；编号存在不等于验证了订单语义或撤单关系。序号列存在、但值为零，也不能用于恢复交易所顺序。

近期共同样本的正价格成交时间倒退同时出现在沪市（22,694次）和深市（41,551次）。深市业务序号为零，沪市正序号也有回退。审计没有通过重排原始流掩盖这些问题。早期标准化文件时间单调，也不能证明原始交易所顺序已保留。动态回放与自身冲击仍需事件字典、跨流排序证据和真实委托回报。

## 现有策略的成本与资金敏感性

诊断覆盖2025-01-03至2025-03-31，共56个交易日。所有情景复用同一执行模拟器、日成交额5%参与率上限、T+1与涨跌停标记；价格采用复权收盘价代理，数量允许碎股。原输入的历史发布时点、公司行动与退市结算仍待核实。原100万元、5基点情景的56日净值复现误差为零；这验证了复现过程，没有验证上述输入假设。

先移除原模拟5基点费用，再替换成本，避免重复计费。税费情景假设买卖各1基点综合佣金、卖出5基点印花税，最低佣金为零，不额外叠加过户费。卖出税费按[2023年8月28日起减半的公告](https://shanghai.chinatax.gov.cn/zcfw/zcfgk/yhs/202308/t468451.html)记录；佣金是假设，不是券商合同。静态成本以现金扣款近似，不模拟日内价格路径或自身冲击。

十二组基准情景使用原三日参考成本，另外六组使用扩展样本10万元／100万元订单的有条件中位数。参考统计包含后续2026年观测，只用于反事实敏感性，不是2025年事前可获得的成本模型，也不随每笔实际订单的金额、深度和时点变化。

| 初始资金 | 无成本期末净值 | 假设税费 | 税费＋扩展10万元参考 | 税费＋扩展100万元参考 |
| --- | ---: | ---: | ---: | ---: |
| 1000万元 | 1.307825 | 1.305736 | 1.299470 | 1.291617 |
| 1亿元 | 1.307982 | 1.305893 | 1.299624 | 1.291767 |
| 10亿元 | 1.299669 | 1.297823 | 1.292200 | 1.285138 |

十八组约束模拟的每日现金均非负。无成本模型的累计买入委托完成比例从1000万元时的95.3%，降至10亿元时的68.6%；分母是累计成交与未成交委托金额之和，不是期末待成交量。模型中的日均单边换手约4.74%和4.31%，与另设的60%压力情景不同。费用会改变后续可用资金和订单，所以净值差额不等于简单累计费用；未成交总额降低，也不必然表示更容易成交。

另有十二组按原成交记录替换费用的固定路径反事实。它们保留原持仓损益和未成交结果，现金不足时明确记录资金缺口，不能视作可执行净值。使用此前三日参考成本、250个交易日、每日买卖各60%的仅成本压力测试，分别报告线性支出和复利损耗；两者都不是策略实现收益，也不是这份56日诊断的年化结果。
