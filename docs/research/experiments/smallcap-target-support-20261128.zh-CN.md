# 三组低换手目标组合已有统一的支持集契约

[English](smallcap-target-support-20261128.md)

下一轮账户实验已有三组可复现目标：共同支持集基准、剔除最高换手五分之一、选择最低换手五分之一。完成的是目标构建与算术核对，共同账户、可执行收益和策略有效性尚未完成。

保留面板有566,283条股票—形成日记录、138个日期。先形成全归档股票池及按规模划分的最小20%，再查看低换手评分。三组使用相同的有限原始评分支持集；缺分数仍计入原始股票池的缺失记录，未来收益与其他财务描述符不决定支持集。2015年2月27日原始评分全部缺失，明确记为不支持。137个支持日期覆盖2015年3月31日至2026年7月31日。仅在支持日期内，最小20%平均评分覆盖率为96.28%，全池为96.81%。这个条件基准不等于完整、无条件的合格股票池。

## 新诊断发现了什么

最小20%股票池内，三组均采用目标等权：

| 对照组 | 平均目标股数 | 相对共同基准的低波动暴露 | 相对共同基准的成交活跃度暴露 | 平均目标权重变化 |
| --- | ---: | ---: | ---: | ---: |
| 共同支持集基准 | 799.6 | 0 | 0 | 10.55% |
| 剔除最高换手五分之一 | 639.3 | +0.164 | −0.165 | 13.69% |
| 选择最低换手五分之一 | 160.3 | +0.546 | −0.667 | 25.84% |

暴露使用当期全归档描述符的总体标准差，不额外缩尾。任一入选股票缺少描述符，该期相应暴露保持未知，同时报告覆盖。未知行业权重也保留；小盘低换手组约为7.68%。历史资格及行业版本尚未认证。

目标权重变化为相邻来源日期目标权重差绝对值之和的一半，包含新增与退出。第一期未知；已知不支持日期会重置比较。每组表格均值使用136次变化。这里不包含价格漂移、实际订单、成交、费用、现金、停牌或结算，因此不是实际策略换手、交易成本，也不是两者的预测。账户时点契约还须验证日历完整性。

买入个股换手率低的股票，目标名单仍可能每期变化较大。本例低换手选择组的目标变化高于较宽的基准。三组广度按设计不同，这不是固定K后的机制归因。结果支持继续检验持有缓冲和同账本对照，不能据此认定扣费后策略较差。

## 构建与核对

共同评分股票数为n时，每端取ceil(0.2n)，以股票代码稳定处理并列。剔除组移除低换手评分最低的股票；选择组保留最高分。至少需要五只共同评分股票。每组充分投资、目标等权，仅是诊断约定，不代表可执行股数或现金政策。

本次得到822组归一化的形成日／股票池／对照组目标。独立重算检查了全部正权重与权重和、重复身份，以及六种股票池／对照组的816次相邻变化。逐股目标保留在仓库外，不公开发布。五项回归测试覆盖支持集、缺失暴露、不使用未来收益过滤、目标变化及断点、未知行业与无效身份。
