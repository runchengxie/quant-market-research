# 海外盘面对 A 股的领先信息：时间、控制变量与 ETF 成本

[English](overseas-leadlag-20261018.md)

**当前结论：继续作为探索性研究，不进入生产策略。** 开盘跳空的预测信息大部分与美股共同因素重叠。控制 A 股自身表现、汇率和 SPX 后，恒生、日经、韩国综合指数的增量不稳定。历史 API 到数时间与 ETF 实际成交均未得到认证。

**证据阶段：** 2026-10-18 审阅的日频历史滚动检验，数据截至 2026-10-16。此前探索已看过部分年份，这轮按年份向前滚动属于历史复核，不是新取得的独立样本外证据。公开内容包括方法和汇总结果；供应商行情与逐日预测保存在仓库外。

## 这轮改变了什么

第一轮分别预测指数的开盘跳空和开盘至收盘收益。其中按指数日内收益计算的多头择时是假设性结果。普通境内股票 ETF 实行 T+1，不能把“开盘买、当天收盘卖”直接当作可执行收益。本轮分别回答：

1. 北京时间 08:45 前已完成的海外日线，能否改善 A 股指数预测？
2. 按开盘价进入 ETF，并至少持有至下一次可交易开盘，这些信息是否改善多头／现金切换结果？

第二个持有窗口还包含一次隔夜，因此不等同于第一天的开盘至收盘收益。预测出开盘跳空，也不表示能在已经反映该跳空的开盘价之前成交。

## 时间与数据核查

信号时点固定为北京时间 08:45。每条海外行情先按本地时区换算为 UTC，再检查是否早于决策。美股使用纽约时区及其夏令时；香港取本地 16:10，日本按历史日期取 15:00／15:30，韩国统一取较保守的 15:30；之后均额外留一小时发布缓冲。正常全日收盘时间也保守覆盖提前收盘的半日市，但这并不独立证明源数据没有缺少交易日。[NYSE 时间说明](https://www.nyse.com/trade/trading-information)、[香港交易时段](https://www.hkex.com.hk/Services/Trading-hours-and-Severe-Weather-Arrangements/Trading-Hours/Securities-Market?sc_lang=en)、[东京 2024 年交易时间变更](https://www.jpx.co.jp/english/corporate/news/news-releases/1030/20241103-01.html)。

TuShare 的 FXCM 外汇日线按 GMT 日期标记。本轮对美元兑离岸人民币、美元兑日元、欧元兑美元取买卖报价中间价，等 GMT 当天结束后再留一小时。因此前一个 GMT 日期的完整日线，假定到北京时间次日 09:00 才可用，不能用于 08:45 决策。这是有意保留的时间缓冲。[TuShare 外汇日线定义](https://tushare.pro/document/2?doc_id=179)。

海外信号使用相邻两次 A 股决策时点之间，最新可用收盘价的变化：A 股长假期间的海外涨跌会累计，海外休市时同一报价不会反复生成新涨跌。超过十个自然日的旧报价标为不可用。另设一组敏感性，把所有海外及汇率输入再延迟一个 A 股观测日。

| 核查 | 结果 |
| --- | --- |
| 各目标、各延迟情景累计的来源选择记录 | 148,568 条 |
| 假定可得时间晚于决策时间 | 0 条 |

| 512480 多出的一条因子日期 | 2021-03-26，为已确认的份额拆分停牌日 |

**这些核查证明的是假设时点下的先后关系，不是历史 API 准点率。** 原始输入都是本次下载的最终历史数据，供应商在当时可能晚发、修订或缺失。没有补造历史抓取时间，因此尚不能认证为严格的历史可得数据回测，也没有新增前瞻观察期。

## 控制变量与年度滚动

每个模型都使用普通最小二乘回归，均值和标准差只从对应训练期计算；ETF 规则固定为预测收益大于零时持有，否则持有现金，没有按测试年收益调参。

- **A 股自身＋汇率：** 前一期自身指数／ETF 收益、五期动量、二十期波动；前一期沪深 300 收益及五期动量；离岸人民币、日元、欧元汇率变化。
- **加入美股共同因素：** 上述控制加 SPX。
- **加入亚洲盘面：** 再加恒生、日经、韩国综合指数。

2020—2026 年逐年扩大训练窗口，每年单独拟合，至少要求 252 条先前有效训练样本。训练标签的结束时间必须早于该测试年的第一笔决策：例如前一年最后一笔 ETF 持有收益如果到新年开盘才结束，就会从训练集剔除。指数有七个年度切分；512480 在上市后积累足够训练数据，自 2021 年开始评估，共六个年度切分。2026 年均为截至 10 月的部分年份。

## ETF 与成本

510300 提供宽基代理，512480 提供半导体代理。512480 的跟踪指数与本研究的申万半导体指数不同，不能把两者当作完全相同的组合；两只产品也是事后从存续产品中选择，没有完成历史全 ETF 股票池检验。

持有收益按 `原始开盘价 × fund_adj` 计算，避免把份额拆分当成突然亏损。涨跌停开盘保护也按拆分调整参照价。512480 在 2021-03-26 因拆分停牌，3 月 29 日复牌，对应一笔“下一次可交易开盘”间隔长于一个 A 股交易日；年化 Sharpe 仍采用 252 个观测间隔的近似。[上交所拆分与停牌公告](https://www.sse.com.cn/disclosure/fund/announcement/c/2021-03-17/512480_20210317_1.pdf)、[ETF 交易规则常见问题](https://www.sse.com.cn/assortment/fund/etf/question/)、[ETF 日线字段单位](https://tushare.pro/document/2?doc_id=127)。

连续看多会保留原有持仓，成本只对买入、卖出和期末清仓收取。入场前检查此前二十个观测日的平均成交额，将 TuShare 的“千元”换算为元后，用固定参考金额的 1% 参与率上限判断；接近对应 10% 涨跌停的开盘价保守阻止相应方向的交易，卖出受阻则继续持仓。这只是在日线上的限制近似，不能证明开盘集合竞价真实成交。

| --- | ---: | ---: | ---: |
| 510300 每个观测间隔平均净收益 | +0.70bp | −2.58bp | +1.67bp |
| 510300 近似年化 Sharpe | 0.13 | −0.45 | 0.21 |
| 512480 每个观测间隔平均净收益 | +8.41bp | +7.17bp | +6.42bp |
| 512480 近似年化 Sharpe | 0.63 | 0.54 | 0.41 |

半导体的美股共同因素模型在这段历史中为正，但加入亚洲盘面后平均收益下降。这仍不足以投入生产：历史到数、ETF 选择、开盘成交及现金分配尚未完整核验。两只 ETF 的评估日期不同，也不能直接按上表高低比较产品优劣。

公开文件保留了 224 个成本情景，包括两种信息延迟、四种持仓规则、双边合计 0/5/10/20/40bp，以及 1 万／10 万／100 万元参考金额。在金额情景中，假设单边佣金 3bp、最低 5 元，再加单边 1/5/10bp 滑点；这些是研究假设，不是实测券商费率。参考金额固定用于费用与成交额准入，而收益会复利，因此不能将其解释为持续增长账户的实际容量。整手取整、盘口冲击、现金分红账本、期货换月及历史费率未完整回放。

## 复现与公开范围

在本仓锁定环境中运行：

```bash
PYTHONPATH=src python -m market_research.studies.overseas_leadlag.run \
  --index-inputs /external/index-histories \
  --extra-inputs /external/fx-and-etf-histories \
  --output /external/new-task-output
python scripts/export_overseas_leadlag_public.py \
  --input /external/new-task-output/reviewed_summary.json \
  --output /external/reviewed-public-summary.json
```

指数目录包括四份 `{hsi,n225,ks11,spx}_tushare_daily.csv`，以及 `000300_sh_tushare_daily.csv`、`801081_si_sw_daily.csv`。补充目录包括 `{usdcnh,usdjpy,eurusd}_fxcm_fx_daily.csv` 和 `{510300,512480}_sh_{fund_daily,fund_adj}.csv`。文件均需 `trade_date`，其余字段沿用对应 TuShare 接口，`fund_daily.amount` 为千元。输出必须是仓库外的新目录，保留输入 SHA-256、时间连接、训练区间、逐日预测及成本结果。

公开导出只允许汇总比较、分年结果、成本情景、训练边界及审计元数据。行情原始行、私有逐日预测、供应商凭据和本机路径不会进入公开投影。可选绘图脚本 `scripts/plot_overseas_leadlag.py` 用 Matplotlib 从汇总 JSON 生成图，不读取原始行情。

下一项能提升证据等级的工作，是在真正的前瞻期保留决策前抓取回执，再以集合竞价或分钟数据核对执行代理。本次发布保留当前历史结果和限制，尚不构成生产策略验收。
