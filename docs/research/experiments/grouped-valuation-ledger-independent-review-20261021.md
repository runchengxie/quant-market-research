# 交易约束估值研究：独立方法审查

日期：2026-10-21。审查者：独立子代理 `ledger_review`。范围：研究口径、主代理转交的源码片段、实际运行收据摘要，以及成交审计补强设计。审查者两次远端只读调用在进程创建阶段因自动权限审批超时失败；因此这不是审查者亲自远端读取全量产物后的复核。落盘重放与成交条件检查由单独脚本和收据提供。

## 发现与处理要求

1. P2：原成交条件审计中的 SQL NULL 语义可使空成交价漏检，异常买卖方向也可能绕过方向限制。应显式拒绝空值、非有限值、非正价格/数量/成交额、负费用以及非 buy/sell 方向。针对性测试必须使用哈希匹配的损坏输入，以免只测到哈希层。
2. 成交审计独立运行时应核验原收据列出的订单和摘要、成员文件、价格文件；拒绝价格重复主键和冲突的成员退市日期，并在结束时重新校验输入。结果应写入新目录，保留原审计和冻结账本。
3. 空末期持仓 CSV 应保留固定列头，以便自动复核。
4. 同收盘先卖出、再按确切净卖出所得分配买入预算，包含价格已知和资金顺序假设；日线不能证明排队成交、实际容量或可执行的竞价顺序。

独立审查认为拟议修正覆盖了 P2 的漏检路径；只有补丁落盘、针对性回归与新的成交审计通过，才可认定该问题已修复。实际执行结果以最终检查点收据和测试日志为准。

## 联合解读的边界

成交条件审计只检查已经标为 filled 的订单。遗漏订单、错误拒单、预算分配和账务恒等式不由该脚本证明，必须结合状态机测试和持久化账本重放。两个审计应关联同一个冻结运行收据。

已有证据未显示本轮资金或持仓计算错误。已完成的 40 个组合各 748 日，末期严格收益仍有 39 个未知；主情景十组全部未知。零估值敏感性不得命名为完整已实现收益、保守收益下界或可交易保证。

复权单位模型并非真实股数现金账本。公司行动完整性、退市回收、排队与容量、财报历史修订、ST 小样本和覆盖不足仍是限制；必须继续保留 `raw_share_ready=false` 和 `revision_safe=false`。

建议额外固定原 receipt.json 自身的起始哈希并在结束时复核，以明确审计期间使用的是同一个收据快照。本次原始运行产物保持冻结；该建议不构成已有数据被修改的证据。
