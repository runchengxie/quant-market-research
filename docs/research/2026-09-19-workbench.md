# 风格因子工作台：计算与来源修订

## 本次修复范围

本次修正本仓分位收益原语与独立市值诊断，不把这些修复等同于重新验证 19 个历史因子收益。两条生成链路相互独立。

- 形成日仅使用当时可见的因子值、价格和证券资格。按分数排序、同分按股票代码排序，以 `ceil(rank × Q / N)` 分组；组大小差不超过一，样本不足时保留空组语义。
- 未来目标日期来自输入的全市场交易日历，不跳到某只股票下一条恰好存在的报价。输入缺失完整交易日仍是数据限制。
- 分组人数是形成时人数。新增已观测、缺失收益人数和覆盖率。收益覆盖不完整时，完整组合的均值与中位数为空；可用部分的均值单独标为 `observed_only_*`，不作为完整组合收益替代。
- 缺失不填零，不猜测退市终值。未来能否新建仓与已持仓股票有无有效估值报价分开处理。
- 单调性与尾部收益差基于请求分组均完整的共同形成日。缺样本、缺组、重叠尾部与非有限值不会被解释成零效应。
- 月度图原本已经对月份等权。本次纠正上一轮报告对此的误述，补齐缺失值、分组数字排序及共同日期测试。十分组日度、月度曲线统一使用十组完整的共同日期，再计算月均值并对月份等权；阶段尾差使用两端共同日期。剔除的日期和月份仍构成选择限制，不能把这些图当作显著性检验。

## 尚不能据此重建的历史结果

19 因子历史收益由另一个月末五分组、固定份额多空组合流程生成，不调用本次修正的两个分位函数，所以不因这些函数变更而机械替换。

全量历史重建还需恢复或确认生成代码版本、冻结同版本输入，解决迁移后财务 vintage 发现路径的变化，并单独审计后续财报修订和持有期缺失收益。原流程存在持有期缺失收益填零；不能通过网页美化把它称作已验证收益。

`quality_component_summary.csv` 是独立短样本产物，其原始生成记录尚未定位。页面保留数值但明确来源限制，不宣称完成与 18 年复合 Quality 的贡献归因。

## 市值诊断的版本化重算

使用 `a_share_all_20150101_20260918_daily_clean` 输入版本，截取至 2026-09-07，以修订后 `report barra` 命令重新计算。算法提交为 `470dfa9de7e1a825a06e47f1728e19239041709e`。原 9 月 7 日输入版本未恢复，因此这属于 revised-vintage 结果，不是历史版本的精确重演。

重算得到 28,380 条分组记录、2,838 个形成日、10,853,685 个形成成员记录。其中 10,544 条没有有效的目标日报价，6,770 条分组收益不完整，完整组合收益留空。

十组同时完整的形成日仅 631 个，另 2,207 日未进入全分组共同样本诊断。这一筛选仍可能产生条件选择偏差，不能因为形成分组不再前视就宣称结果完全无偏。

共同完整日期上的最小组减最大组平均日收益差约为 0.0671%，相邻分组单调性比例为 6/9。旧快照对应数值约为 0.1994% 和 8/9。输入版本和缺失政策均有变化，这个差异不是只归因于算法修正的对照实验，也不是显著性结论。

独立检查覆盖全部聚合记录的成员数、覆盖率、缺失值、分组均衡、共同日期指标；另外对 2015-01-07、2020-03-02、2026-09-04 三个形成日直接查询源数据，独立排序分组和查找目标日价格，与结果对照。抽样验证不是全量原始数据审计。公开 `size_revision_audit.json` 保存版本、校验摘要和比较限制，不含个股原始记录与本地路径。

### 发布后补充：初始 HTML 完整性

对发布产物做原始字节校验后，发现 Barra 页初始 HTML 有两处 NUL 字符；CI 下载产物与线上文件一致，因此不是网络传输问题。旧构建加上新增校验后可以稳定复现失败，符合 [React 18 Node 流式渲染的上游问题](https://github.com/react/react/issues/31134)。

精确将构建中的 `react-dom/server` 映射到同版本的 `react-dom/server.browser`，由 Astro 使用已有的 Web Streams 渲染路径；不修改客户端 React，不升级依赖，不关闭流式渲染或丢弃 `identifierPrefix`。现有页面在服务端先输出加载状态、在浏览器加载研究数据。将来若引入服务端挂起的数据组件，需要重新检查 Suspense 完成和错误传播语义。

静态校验现会拒绝所有 HTML 中的 NUL 与无效 UTF-8。补充回归覆盖未经浏览器修复的响应正文、准确中文、客户端挂载错误与分页 ARIA 引用。修订后完整 Pages 构建通过，前端测试 91 项、浏览器测试 25 项通过；研究数据与算法未作额外改动。
