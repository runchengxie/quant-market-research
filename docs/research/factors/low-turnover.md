# 低换手：它可能在替哪些东西“说话”？

> 研究状态：探索性证据，不是已确认的独立溢价或可直接交易策略。
> 底层候选研究：2015-02 至 2026-07；开发样本 2015–2023，2024–2026 仅作描述性观察。历史风格诊断另覆盖 2008–2026。

## 先用一句话理解

低换手不是“股票没人交易，所以一定会涨”。它是一个容易同时映出好几种股票特征的温度计：价格波动较低、交易热度较低、流动性不同、短期追涨杀跌较弱，可能还有市值和投资者关注度的影响。它目前更像**代理变量或复合信号**。现有结果没有证明这些力量彼此有因果上的“协同效应”；要证明协同，必须显式检验交互项或做预先设计的条件实验。

打个比方：体温高能提示感染，却不能单独告诉你病因。低换手的收益差也一样，不能从一个指标直接推断“冷门导致低估”。

## 到目前为止看到了什么

### 最初的强结果对定义很敏感

2008–2026 的月末单日换手率多空年化收益约 25.97%，Sharpe 2.05，最大回撤 -17.97%。但把单日读数换成更平滑的过去 20 或 60 日均值/中位数后，多空年化收益落在约 9.47%–15.88%。这说明单月最后一天的交易状态把原始数字推高了；平滑后仍有历史关系，但强度明显较低。

| 信号定义 | 多空年化 | Sharpe | 最大回撤 |
| --- | ---: | ---: | ---: |
| 月末单日换手 | 25.97% | 2.05 | -17.97% |
| 20 日平均换手 | 15.88% | 1.26 | -22.60% |
| 20 日中位换手 | 13.72% | 1.12 | -23.95% |
| 60 日平均换手 | 11.76% | 0.99 | -22.33% |
| 60 日中位换手 | 9.47% | 0.83 | -23.03% |

这些是历史分组收益，不含完整的可交易性审计。多空的高换手腿是理论空头，真实融券、借券费和冲击成本没有完整计入。

### 控制其它特征后，信号变弱

在共同股票样本上，每个月先把低换手信号对指定特征做截面回归，再用残差排序。开发期平均 Rank IC 和低换手减高换手月收益差如下：

| 逐步剥离的特征 | 平均 Rank IC | 月均低减高收益 |
| --- | ---: | ---: |
| 原始信号 | 0.0730 | +1.60% |
| 加市值 | 0.0790 | +2.06% |
| 再加低波动 | 0.0262 | +0.96% |
| 再加成交活跃度、Amihud 型流动性 | 0.0078 | +0.72% |
| 再加滞后动量、短期反转 | 0.0210 | +1.11% |

“先加市值反而变强”表示这组样本中，市值控制没有削弱排序，不能简单说低换手只是小市值的别名。加入低波动后，IC 和收益差明显收窄；加交易活跃度与 illiquidity 代理后，Rank IC 接近零。再加动量/反转后略有恢复。这种不规则变化说明各代理变量彼此相关、回归顺序会影响结果，不能把每一行看成严格的因果拆账。

两条腿也很有启发：原始组低换手腿平均月收益约 +0.38%，高换手腿约 -1.23%；控制市值与低波动后，两腿分别约 +0.01% 和 -0.95%；加流动性代理后分别约 -0.09% 和 -0.81%。低换手多空差相当部分来自“少买表现较差的高换手股”，不只是低换手股票自己大涨。

### 在不同市值组内，低换手效果并不平均

先按行业内相对市值分五组，再在每组里按换手率分五组。以下为每月组内低换手减高换手，括号内 HAC(3) t 值：

| 相对市值组（从小到大） | 2015–2023 开发期 | 2024–2026 描述期 |
| --- | ---: | ---: |
| Q1 最小 | +0.41% (0.96) | +0.87% (1.32) |
| Q2 | +1.69% (4.16) | +0.76% (1.03) |
| Q3 | +2.01% (5.20) | +0.94% (1.08) |
| Q4 | +1.89% (4.52) | +0.49% (0.43) |
| Q5 最大 | +1.27% (2.33) | -0.67% (-0.48) |

开发期优势主要出现在中间市值组，最小组最弱，因此不能把它概括成“微盘股里的低换手最强”。描述期每组都只有 30 个形成月，t 值都较低；又因这个区间已在多轮研究中反复查看，它不是干净的最终样本外验证。

### 更像投资的检验，结果谨慎得多

一项独立的 2015–2026 多头组合测试，在 10bp 成本假设下，低换手多头净年化约 5.44%、Sharpe 0.33、最大回撤 -51.84%；规模与低波动残差化后的低换手组合净年化约 -10.11%。这比抽象的多空因子收益更接近“真的买入并持有会怎样”，但仍依赖回测模型、股票资格重建和成本假设。

同一研究的执行账本还显示：原始小盘复合组合在成交约束下回测收益有时反而升高。逐笔归因表明延迟/部分成交会绕开一些后来亏损的交易；这属于模拟路径效应，不是“限制越严 alpha 越高”。影响成本参数当前为 0 bps 的那次主运行，不能据此声称冲击成本已验证。

后续用同一组锁定的信号与月频/双周频持仓，对参与率滑点参数做了 50/100 bps 账本敏感性（另计 10 bps 交易费，仍限制在前一交易日成交额的 5%）：

| 滑点参数 | 调仓频率 | 净年化 | Sharpe | 最大回撤 |
| ---: | --- | ---: | ---: | ---: |
| 50 bps | 月频 | 14.44% | 0.64 | -51.72% |
| 50 bps | 双周频 | 13.84% | 0.62 | -59.88% |
| 100 bps | 月频 | 13.88% | 0.62 | -52.33% |
| 100 bps | 双周频 | 13.54% | 0.61 | -60.42% |

50→100 bps 时年化净收益再降约 0.56 个百分点（月频）和 0.30 个百分点（双周频）。这只是参数化参与率滑点敏感性，不是经券商数据校准的冲击曲线；它仍用了前一日成交额约束，**不是 ADV20**。早期 0 bps 文件没有记录生成它的代码提交，因此不把 50/100 bps 数字与其计算差额解释为纯冲击成本影响。

另用 2015–2026 现金账本，对低换手多头按前 20 个市场交易日成交额均值计算 ADV，并限制单日成交不超过 ADV 的一定比例。在 1 亿元规模、10 bps 交易费、滑点参数 0 bps 下，5% ADV 的净年化约 5.12%、Sharpe 0.32、最大回撤 -53.03%、填充率 85.3%，平均现金 1.1%。这是新的 ADV 容量筛查结果，不能与旧版连续权重低换手组合的 5.44% 直接相减；两个执行记账口径并不相同。

在同一 ADV20 现金账本上再加 50 bps 参与率滑点参数，参与上限 1%/3%/5% 时净年化分别约 4.91%/4.91%/4.63%，Sharpe 为 0.32/0.32/0.30，最大回撤为 -50.67%/-53.21%/-53.58%；对应填充率为 67.4%/81.9%/85.2%，平均现金为 9.1%/2.1%/1.0%。1% 与 3% 的收益几乎相同；路径延迟会改变实际持仓，因此各项指标不是单纯的“成本折扣”。

在 5% ADV20 下把滑点参数从 0 提到 50、100 bps，净年化依次为 5.12%、4.63%、4.11%，Sharpe 为 0.32、0.30、0.29，最大回撤为 -53.03%、-53.58%、-54.14%；填充率约 85% 且平均现金约 1%。这个结果显示所选滑点参数会继续压低收益，但滑点仍是研究敏感性，不是经券商校准的市场冲击估计。

## “代理变量”“组合效应”“协同效应”有什么区别？

- **代理变量**：低换手与其它特征一起变化，因此能间接识别一组股票特征。当前证据支持这种可能。
- **组合 / 复合信号**：低换手排名把低波动、交易活跃度、流动性、动量/反转等信息揉在一起。剥离后信号大幅衰减，也支持它有复合成分。
- **协同效应**：A 与 B 同时出现时，效果超过 A 与 B 各自效果的简单相加。这需要事先定义 A×B 交互项、比较不同组合格子并有足够独立样本。现有相关性、逐步回归和分组收益都没有证明它。

因此更稳妥的结论是：**低换手是有历史预测信息的复合型代理信号；它是否有独立、稳定、可交易的增量价值尚未确定。**

## 接下来怎么查

| 优先级 | 检验 | 要回答的问题 | 通过标准/停步信号 |
| --- | --- | --- | --- |
| 1 | 用月末可得数据做完整截面模型：行业、市值、波动/贝塔、价值、盈利、动量、反转、流动性，并留出逐年滚动窗口 | 残差低换手是否在样本外稳定？ | 预先冻结定义；同时报告系数、Rank IC、组合两腿、置信区间，禁止按 holdout 挑模型 |
| 2 | 正交双排序及明确的低换手×低波动/流动性交互项 | 是可加的独立效应，还是只有特定组合才有效？ | 报告格子收益与交互项置信区间；称“协同”前交互项须稳定为正 |
| 3 | 使用形成日前 20/60 日滚动 ADV、价格门槛、停牌/一字涨跌停不可买卖规则，做 T+1 成交；从 0 到 20/50/100bp 冲击成本 | 信号能否被真实执行？ | 将实际 fill、未成交现金、持仓锁定、退市价值和借券限制计入；不以延迟躲跌的回测优势当 alpha |
| 4 | 按换手分位检查波动、偏度、极端收益、涨停、近期收益和换手变化；以预先选定的组合做机制拆分 | 更像避开投机过热/反转，还是补偿低流动性？ | 独立时期重复；机制特征加入后，核心残差关系方向一致 |
| 5 | 对多重尝试使用时间序列块自助法/多重检验校正，并且只留真正未看过的未来样本作最终验证 | 现有显著性是否被相关性和反复试验夸大？ | 预注册实验、固定终点；不把已查看过的 2024–2026 再包装成新 holdout |

暂不推荐把当前低换手单因子或复合组合升级为正式策略。先在 `quant-research` 的正式实验边界里完成逐年验证和可成交的 ADV/冲击模型；本仓库保留可复核的研究摘要与方法说明。

## 数据出处与口径边界

本页综合历史定义诊断（2008–2026）与候选组合归因实验（形成期 2015–2026）。后者数据截至 2026-07-31，使用每月形成日前已观测的滞后特征；开发期为 2015–2023，2024–2026 只作描述。双重排序里的市值是行业内 `size_score` 相对分位，不等同于全市场绝对市值分组。候选实验的历史 PIT 修订安全尚不完整，ST 状态属于重建 PIT；结论需视为探索。

不应把不同实验的收益、窗口、持仓和执行引擎拼成一条序列。完整运行结果与原始输入留在受控数据资产目录，不进入本仓库。
