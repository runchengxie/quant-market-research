# Barra 风格研究资料清单

项目中的 18 年风格页面只展示经过筛选的公开结果。相关研究还分散在 `quant-research` 和 `quant-platform` 的计算代码、方法说明与实验记录中。这份清单说明哪些资料适合整理进公开研究，哪些内容需要继续留在内部仓库。

## 可以整理到公开研究的资料

| 来源 | 可整理内容 | 公开时需要保留的边界 |
| --- | --- | --- |
| `quant-research` 的 `style-factor-market-regimes-2008-2026.md` | 2008 年以来的风格阶段、年度表现、因子相关性和数据覆盖 | 标记为研究筛查级，说明财务数据和交易约束仍有限制 |
| `quant-research` 的 `style-factor-constrained-robustness-2008-2026.md` | 股票池、ST、停牌、涨跌停、退市和成本约束的敏感性框架 | 只发布已审核的汇总，不发布原始股票明细 |
| `quant-research` 的 `barra-long-only-2008-2026.md` | 多空结果转为多头 Top-100 的可执行性比较 | 明确这是历史筛查结果，收益口径和交易限制并不完整 |
| `quant-research` 的 `barra-factor-rolling-odds.md` | 滚动持有胜率、失效期和恢复时间 | 不能把滚动赔率当成未来概率 |
| `quant-research` 的 `low-turnover-factor-diagnostics-2008-2026.md` | 低换手窗口、分组单调性和中性化诊断 | 与当前低换手公开页面分开标注样本、版本和收益口径 |
| `quant-platform` 的 `factor-risk-model.md` 与 `style-factor-cross-sections.md` | 因子暴露、协方差和形成日截面的通用定义 | 作为方法说明，不把通用风险内核描述成商业 Barra 复刻 |

这些资料共同补充三个问题：历史风格收益是否跨阶段出现，收益对股票池和交易限制是否敏感，以及风格收益如何进入风险归因。公开版本应使用研究摘要、方法和审计结果，完整运行产物继续保留在外部数据目录。

## 继续留在内部仓库的资料

`quant-research` 中的 Qlib 试验、因子组合搜索、长期多头策略细节、基金持仓和未发布的分钟或 L2 研究，包含参数探索、私有策略判断或未审计数据。这些内容可用于设计后续实验，但不应直接复制到公开网站。

`quant-platform` 中的执行内核、风险模型实现和测试可以继续作为公共基础设施维护。涉及账户、交易接口、内部路径或生产配置的内容不进入研究报告。

## 当前公开页面的覆盖

公开页面目前包含：

- 19 个历史风格因子的合成收益、年度结果、相关性和市值十分组诊断
- Quality 四个子因子的 2020 年以后快速诊断
- Barra 风格因子定义字典和版本边界
- 低换手的点时分组修正、执行账本和窗口敏感性

页面仍没有完整呈现上述内部资料的全部结果。原因是不同报告的股票池、形成日、收益窗口和成本假设并不完全一致。后续每加入一项内容，都应先建立对应的来源清单、数据范围和质量状态，再更新网页摘要。

## 下一步整理顺序

1. 先把 `style-factor-market-regimes-2008-2026.md` 与约束稳健性附录的共同口径整理成一份公开阶段摘要。
2. 再从 long-only 和滚动赔率报告中提取回撤、失效期和成本后的对照表。
3. 等完整 PIT 财务数据可用后，单独发布 Quality 子因子长期对照。
4. 暂不公开 Qlib 组合搜索和未审计的分钟或 L2 结果。
