# 小微盘信号需要在最终持仓上检查风格

[English](smallcap-style-attribution.md)

## 当前判断

值得建立透明、可复算的公开风格拆解。先做持仓暴露和口径匹配的收益归因，风险预测另行验证。已有的19因子历史快照主要是排序组合收益，不是完整的商业Barra复刻。`risk_adapter.py`只规范调用方提供的面板；截面因子收益、协方差和归因已有`quant-platform.analytics.risk_model`及`quant-platform.analytics.factor_attribution`接口，不在研究仓库重写一套风险引擎。

本轮复核低换手、交易成本和压力流动性资料，并新运行归档面板上的持仓广度与暴露诊断。没有新增收益观测、认证历史入选资格、确立最优持股数或校准市场冲击。

## 风格拆解需要分别回答什么

- **暴露**：相对明确的股票池等权或市值加权基准，最终持仓偏向哪些市值、波动、流动性和行业特征？
- **已实现收益归因**：用收益区间开始前已知的暴露，解释主动收益中的市场、行业与风格贡献，保留无法解释的残差。
- **风险预测**：只使用历史数据估计因子协方差与特质风险，再检查未来风险及压力期的预测误差。

因子IC、排序组合收益、条件回归系数和风险贡献不是同一个量。因子历史收益为正，也不自动意味着应该限制其暴露。回归残差只表示模型尚未解释的收益，不能直接称为纯选股Alpha。

## 新运行：残差化不保证Top K风格中性

保留的去混杂面板包含566,283条股票—形成日记录，覆盖2015年2月至2026年7月的138个形成日。历史股票资格与行业标签版本尚未认证。这里沿用原始低换手评分，以及已有规模、低波动、流动性和历史收益控制后的残差评分，没有重新生成这些评分，也没有恢复原始输入。

分别在全归档股票池及其中市值最小20%的股票内，选择K为10、30、50、100、150、300、400的最高分股票；比较等权与平方根排名加权。最小20%是相对样本分组，不等同于绝对微盘定义。两种信号、两个股票池取共同形成日，不依据未来收益筛选。每个描述符按当期全归档股票池的可用观测均值、总体标准差标准化，不额外缩尾；同时计算相对全池及局部股票池的暴露。

在2015年6月至2026年7月的134个共同形成日，等权结果如下：

| 股票池／信号 | K | 相对局部股票池的低波动暴露 | 相对全股票池的市值暴露 |
| --- | ---: | ---: | ---: |
| 全池／原始低换手 | 50 | +0.908 | +0.699 |
| 全池／控制后残差 | 50 | −1.337 | +0.025 |
| 最小20%／原始低换手 | 50 | +0.697 | −1.176 |
| 最小20%／控制后残差 | 50 | −0.922 | −1.183 |
| 最小20%／原始低换手 | 150 | +0.590 | −1.176 |
| 最小20%／控制后残差 | 150 | −0.455 | −1.181 |

单位为当期全归档截面描述符标准差，按形成日等权平均。低波动评分越高，越偏向归档中的低波动方向。表中六行的市值与低波动暴露均覆盖全部134期；残差分数不等同于校准后的预期收益。

全池中的低换手头部实际上偏向较大市值。限定最小20%后，扩大持股数量仍保留显著的全市场相对小市值暴露。增加K能分散部分持仓集中风险，却不会自动改变股票池本身的规模倾向。

原始低换手与控制后残差的低波动暴露甚至改变了方向。对全截面做线性残差化，并没有约束最高残差股票的最终持仓暴露；非线性关系、误差异方差、行业与缺失选择都值得排查。这不能识别具体成因，也不能证明残差策略亏损，但足以要求对最终持仓直接验收风格。

最小20%内，原始低换手评分与低波动评分的月度Spearman相关性均值约+0.477，与成交额活跃度评分约−0.655，与非流动性评分约+0.499。关联不能解释因果。全池原始Top 50与残差Top 50的行业缺失权重分别约14.2%和15.6%；UNKNOWN必须保留，因此行业HHI不能当成完整的行业集中度结论。

若任一入选股票缺某个描述符，该期相应暴露保持未知，不将权重归一化到剩余股票。入选不足K时按可用股票重配并报告缺额；这只是本诊断的约定，不是账户执行规则。先前未配对形成日的运行保留作记录，以上比较均使用共同日期版本。

## 低换手：部分控制后仍有收益差，可投资性尚未确立

本次来源复核与登记的86期manifest、收益汇总哈希一致。2019年5月至2026年6月形成、正PE且控制变量可用的共同样本里，原始低减高月均毛收益差为1.3821个百分点，控制规模及低波动后为0.8598，完整控制并重新分组后为1.2001。完整阶段的12个月分块区间为0.8692至1.6184个百分点。控制改变了股票排序和成员，阶段间的差不能当作可相加的因果贡献。

136期规模组内比较是另一套样本，不能与86期合并。120日窗口历史结果与重放差异尚未解决。低减高为正可能来自避开高换手输家，因此下一步需在相同股票池、日期及份额／现金账本上比较：股票池基准、剔除最高换手组、偏向低换手组，并保留多空两腿。

已有历史被反复查看，不能称为未触碰样本外。2021年中国换手效应论文摘要支持继续研究，但其1995—2017年样本与过去12个月信号不同于这里的60日归档，不能视为复现。[出版方摘要](https://www.sciencedirect.com/science/article/pii/S0927538X21000585)

## 成本：保留未成交，比统一加几个基点更重要

现有2025年一季度模拟账户已经保留未成交买卖。静态报价／冲击情景与ADV参与率限制仍属敏感性假设，不是经券商订单校准的真实成本。数据适用性复核只覆盖两个日期、106只共同观测股票，尚未验证事件语义或识别因果冲击。不能用这些情景账户的收益差直接拟合通用冲击曲线。

后续需要匹配订单、到达价、成交、费用和时间戳；分开记录显式费用、价差、冲击、延迟与未成交。到达价、决策价和成交价的基准应固定，避免重复收费。缺真实订单时保留情景范围，不宣布已校准滑点。持仓数量、缓冲和资金规模的比较必须共用账户与成本口径，不能以多空毛收益减多头净收益来估计交易成本。

## 压力流动性：成交冷清不等于股灾退出

现有压力研究按每年、每个市值桶中的低ADV月份定义压力，并非按暴跌或被迫卖出定义。2024年1亿至10亿美元桶的低活跃月份ADV统计量约为正常月份的57.6%。这不是未来成交率，也不能直接换算成可执行容量下降42.4%；更小市值桶的合格月份不足，不能补成零或外推。

真正的退出压力测试应预先定义市场／小微盘回撤事件，在事件前冻结持仓，保留停牌、缺失和无法卖出的股票。对齐分钟与报价时钟，核对剩余库存和现金。每日收盘价不能充当随时可成交的买价，未售持仓不能自动换入其他股票。

## 最小可用模型与候选因子

先检验滞后市场贝塔、对数市值与单独定义的非线性市值，短期反转及中期动量，总波动和市场残差波动，换手、成交额及Amihud代理。市场截距与历史行业需使用可识别的参数化：删去一个行业或施加约束。保留标准化参照、缩尾、估计权重、矩阵秩、条件数、缺失与回归残差诊断。

在广股票池上估计风格收益，再同时检查广市场与小股票内部的暴露。只在小盘组内部标准化，会把共同的小市值倾向藏在参照系里。市值加权估计可能降低小股票影响，应与等权估计并列，并报告估计权重实际覆盖。解释性收盘到收盘归因与下一交易时点可执行收益应分开约定。

盈利质量、估值、杠杆需要公告时间正确的历史财务版本，并规定亏损、负净资产和缺报告的处理。已有质量诊断主要是2020年以后前800只股票，不能直接扩成18年小微盘结论。复合质量及其子项不可重复纳入同一回归。

低换手本身也可能是流动性风险指标的一部分。研究其增量时，同时保留“不含候选因子的基准模型”和“加入该因子的扩展模型”；不能先把目标经济效应残差掉，再据此宣布没有信息。原始与正交化描述符并列，检查控制顺序敏感性。

## 后续研究的进入条件

| 方向 | 本轮已完成的探索 | 下一阶段所需证据 |
| --- | --- | --- |
| 低换手 | 哈希、期数及历史版本复核 | 恢复输入，固定支持度与缺失规则，共用多头账本 |
| 广度与暴露 | 新运行共同日期的归档面板诊断 | 历史资格与行业版本，可追溯的形成日记录 |
| 风格收益 | 核对已有平台接口，明确模型契约 | 滞后暴露与完整、可对账的收益区间 |
| 风险预测 | 明确独立验证要求 | 仅用过去的协方差、特质风险及滚动预测检验 |
| 成本 | 复核已发布模拟和报价证据边界 | 订单、到达价、成交、费用、时钟与未成交库存 |
| 压力与容量 | 区分低活跃月和暴跌退出 | 预先规定事件、资金及参与率，保留原成员 |
| 有效因子 | 优先规模、换手、波动、反转／动量；财务因子设覆盖门槛 | 剔除实验、增量预测与口径匹配的净组合改善 |

因子采用共同日期比较、剔除实验和缺失诊断。K及权重寻找稳定区域，不挑单个最优格。进入真正的新评价期前，冻结模型、变换、配置和执行政策。历史协议对12与24个完整持有期存在不同规定，应保留差异，下一轮使用具名、带时间戳的协议；两种期数都不自动代表统计可靠。本次没有注册前瞻组合或启动生产交易。
