# 2008–2014 年小市值成交活跃度补充

这份补充统计使用 `quant-market-data-platform` 已发布的 Tushare A 股 `daily` 和 `daily_basic` 资产，观察按总市值排序后最小 N 只股票的成交额。它用于补齐低换手和微盘研究缺少的早年流动性背景，不等同于低换手策略回测。

## 数据范围

- 日期：2008-01-02 至 2014-12-31
- 交易日：1,702 个
- 观测：11,914 条 N 组日统计
- N：1、10、50、100、200、400、1000
- 过滤：成交额和总市值均为正

结果保存在本机受控目录 `~/data/quant/market-research/outputs/smallcap_turnover_history_2008_2014_v2/`，包括每日分组统计、汇总 JSON 和运行清单。仓库不复制原始行情或逐股数据。

## 如何解读

早年数据可以说明小市值股票的成交环境与 2015 年以后并不属于同一段样本，但它没有提供可靠的 ST、停牌和退市资格字段。因此，成交额统计只用于描述覆盖和流动性背景，不用于估计可交易容量，也不直接支持低换手因子的收益结论。

后续若要把它接入低换手研究，需要在同一形成日股票池中同时计算 1 日、20 日和 60 日换手率，并先固定名单，再处理未来缺价、停牌和涨跌停。这样才能比较长期低换手、短期异常放量和小市值暴露各自贡献了什么。
