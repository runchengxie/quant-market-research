# 下一轮实验

[English](followup.md) · [首轮方法](README.zh-CN.md)

本轮先用保留输入检查报价，再探索组合名单的变化。逐证券结果保存在仓库外。

```sh
PYTHONPATH=src uv run python scripts/run_smallcap_followup.py --pilot "$BMLL_RUN_ROOT" --features "$BMLL_FEATURES" --output "$BMLL_FOLLOWUP_ROOT"
```

输出目录必须位于仓库外且尚不存在。脚本保存输入哈希，输出逐日诊断、各证券未知主动方向比例，以及候选名单和成员更替比较。

## 报价与退出困难

同时检查有效报价全时段价差和报价年龄低于60秒的价差，保留有效时间与新鲜报价时间的覆盖比例。窗口覆盖完整时仍可能出现交叉或无效报价。买一档金额、超过指定订单金额的时间比例需要单独查看，这些数量无法直接推算成交概率。三个半小时窗口也无法还原连续的日内路径。

解释市场事件前，先核对基线与比较窗口之间的公司公告。下一批采集按五分钟窗口保留前序报价，并记录缺失窗口，将价格与股数的变化分开。对结论不利的观测也应保留。

## 扩大候选范围

固定2025年3月18日的特征日期，在十亿美元以下的市值和成交额分组中，每组按稳定哈希顺序取最多四个候选。资格来自保留快照。查询逐笔数据前，先核对历史上市标识和证券类型，保留未匹配、重复映射与随后退出的证券。名单属于回顾性分层探索，历史时点股票资格和概率抽样仍未认证。覆盖与查询成本确认后再增加独立时期。

## 低换手实验

在市值和成交额均为正且通过特征资格筛选的名单中，取最小100只。每月比较直接按排名换入换出，与保留排名仍在150以内的旧成员两种规则，空位按市值从小到大补齐。另列季度调仓的短样本。首次建仓不计入平均更替比例。

退市或失去资格的成员从目标名单移除，但这不代表当时能够卖出。这里只衡量等权目标名单的成员更替。价格漂移、实际换手、收益和执行还需另算。后续须接入复权价格、分红与退市现金流，并核对资格信息和持仓账户。不能将挑选出的试验证券价差直接套给这份名单，作为组合成本估计。

## 基本面与跨市场证据

SEC 财务事实需要和原公告、申报编号一起保存。记录报告期、单位、报表类型和申报日，保留修订版本。信息可用时间要根据申报接收时间核对，日频原型可先只使用形成日前已经提交的报表。最新重述数据不能替代当时可见的数字。自定义标签和变化的会计概念需要逐项映射。详见 [SEC API 文档](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)。下载失败应记录为输入缺失，财务值不能填零。

2024年中国 A 股回撤继续使用冻结净值时间线，并保留成分与资金流字段缺失的说明。跨市场先对齐分组和分母，美股 NBBO 与中国 A 股多档快照各有可回答的问题。因果解释仍需带日期的敞口、资金流和交易记录。
