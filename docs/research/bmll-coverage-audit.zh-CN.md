# 报价研究先核对历史身份

[English](bmll-coverage-audit.md)

`scripts/audit_bmll_coverage.py` 检查固定的回顾性候选名单在指定日期的覆盖。参考表缺失、失效身份和重复有效身份都保留在分母中。只有当天代码恰好匹配一个有效的 `@SIP` 上市身份时，查询才连接 NBBO 报价。

使用 `--candidate-report`、`--dates` 和仓库外的新 `--output` 生成 SQL，再通过 `scripts/run_bmll_query.py` 在已有授权仓库执行。汇总时使用相同参数，并提供 `--response` 和 `--executed-sql`。脚本核对保留的 SQL 与候选请求一致，要求结果完整且没有截断。SQL、响应、输入哈希和研究记录保留在项目数据目录，逐证券供应商结果不公开。

交易时段按纽约本地时间筛选，从09时30分到16时，不含结束时点。需要明确选择完整交易日，脚本没有节假日或提前收市日历。首末报价时间是 SQL 转换后的当地钟表时间，即使传输结果附带时区标记，也不能再当作 UTC 使用。有效价格计数要求买价为正、卖价不低于买价，包含锁定报价。这些计数没有测量报价年龄、可成交数量或按时间加权的覆盖。

## 接下来核对什么

参考记录缺失需要排查映射和覆盖，失效记录需要核对历史身份，仅凭失效标志无法认定退市。代码更名、股类、合并与拆股都需要带日期的标识和公司行动记录。同一代码发生上市身份变化时应保留变化记录。现代快照仍可能包含后来的修订。

扩大压力研究前，先在事件前形成名单，按市值和此前交易活跃程度匹配，并保留随后离开的证券。比较窗口和阈值应在观察结果前确定。一起估计新鲜报价的价差与买盘金额，另报陈旧和无效报价占用的时间。NBBO 无法还原排队位置或全部订单簿。

组合研究应先核对公司行动前后的现金和股数，再报告收益。排名缓冲与固定排名需要比较真实交易换手及成本。财务质量分组需要按申报可见时间使用数据，并处理历史股数和重述。跨市场研究可先统一市场内排名，保留各市场交易制度差异。

三日期试验属于探索，所选日期尚未构成独立验证样本。查询成功后，历史股票池资格和投资收益仍需分别检验。
