# 后续探索执行协议

这份协议把已经提出的研究问题拆成可以单独登记、复核和停止的工作。每次运行都应保存输入快照、代码版本、形成日名单、目标权重、评价区间和结果文件哈希。缺少必要数据时，输出 `blocked` 状态和缺口清单，不补造数值。

## 低换手

### 前瞻验证

每个形成日冻结以下内容：

- 形成日前可见的股票池、换手信号和控制变量
- 目标名单与权重
- 下一交易日开盘至评价日的收益窗口
- 费用、冲击、参与率和停牌处理规则

比较三组组合：基准组合、剔除最高换手组、偏向最低换手组。三组必须使用同一股票池、同一份额账本和同一现金处理。至少积累 12 个完整持有期后，再报告方向和区间，不把已查看过的月份称为独立样本外结果。

### 信号窗口

在同一形成日和执行规则下并列计算 1 日、20 日、60 日和 120 日换手。1 日信号用于观察短期异常放量，20 至 120 日信号用于观察持续交易习惯。比较 Rank IC、低减高差值、净年化、最大回撤、换手和成交额参与率。窗口改变持仓路径，因此结果只做敏感性比较，不直接视为同一策略的优劣排序。

### 判读门槛

只有在点时名单固定、未来缺价不触发换入、成本和停牌规则一致，并且至少有 12 个冻结持有期时，才进入可交易增量判断。高换手排除若只带来很小的收益变化，且没有降低回撤或换手，应保留为描述性结果。

## 微盘与小市值

逐股审计 2008–2016 年异常跳变，至少保留原始收盘、复权因子、复权价格、公司行动匹配、停牌状态、退市日期和成员资格来源。匹配不到公司行动时标记为 `unresolved`，不能自动归因于分红或送转。

通过审计的日期才用于 N=50、100、200、400、800 的收益和水下统计。每个区间同时报告峰值日、谷值日、回本日、下跌交易日、恢复交易日和右删失状态。没有可靠退市估值或成员资格的年份只发布覆盖说明，不发布伪精确的年化和回撤。

## Barra 风格因子

Quality 子因子诊断当前只代表可用 PIT 财务资产覆盖的 2020 年以后样本，主要是前 800 只股票。要生成新的长期结果，必须先满足：

1. 每个形成日有可追溯的 PIT 财务版本和公告时间。
2. 明确 ROE、ROA、杠杆、盈利稳定性和现金流质量的缺失处理。
3. 同时保留旧版复合 Quality 与新版子因子结果。
4. 比较覆盖率、相关性、因子收益、组合暴露和归因残差。

在这些条件满足前，公开页面只展示子因子诊断，不把它扩写成 18 年 Quality 结论。

## 市场板块与 ETF

下一版探索器沿用代表性 ETF 配对，但增加时间范围、累计收益、年化收益、波动率、最大回撤、当前回撤和成交额中位数筛选。每个结果保留实际起止日期、复权口径、指数与 ETF 的配对关系、费用和跟踪误差是否可得。

没有费用、税费或跟踪误差数据时，页面明确显示未提供，不用 ETF 价格回报代替完整投资者回报。扩展到全部行业前，先固定类别字典和代表性配对版本。

## 发布流程与文档架构

公开快照继续由审核后的派生文件提供。将 Node 快照脚本迁移到 Python 前，先固定 JSON schema、字段白名单、隐私检查和失败条件，再用带逗号、引号和换行的 CSV 样例做回归。

Astro 页面继续承载研究正文和交互图表，MkDocs 承载方法、数据契约和运行手册。只有当公开文档数量明显增加，或需要统一版本化内容集合时，才重新评估 MDX 或 Starlight。迁移前后应比较相同页面的 HTML、CSS、JavaScript 和图表加载大小。

## 结果状态

| 状态 | 使用条件 |
| --- | --- |
| `recorded` | 输入、口径、结果和限制均已保存，可复核 |
| `exploratory` | 有结果，但样本外、成本或数据质量仍不足 |
| `blocked` | 缺少必要数据或无法证明点时口径 |
| `retired` | 发现口径错误，结果不再用于结论 |
