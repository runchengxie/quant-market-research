# Quant 家族仓库迁移记录

本页记录 2026-09-09 将市场研究项目迁入 `quant-market-research` 时采用的安排。当前状态请以项目索引和专题文档为准。

迁移保留了原有共享数据目录。新研究默认将结果写入共享数据根目录下的 `research/quant-market-research/`。生产任务没有随代码迁移，避免改变当时的数据和调度路径。

迁移期间，旧主检出包含其他任务的工作树，因此先通过独立分支和工作树完成代码搬迁。合并后再处理主检出路径，并保留旧路径兼容方式。任何路径清理前都要检查其他工作树、虚拟环境、定时任务和跨仓库引用，避免影响并行任务。

仓库继续作为独立公开项目维护，Python 包 `market_research` 和命令 `market-research` 沿用原名。GitHub Pages 改用相对站点路径，并通过正常的 `main` 构建发布。旧站点地址不保证自动跳转。

迁移没有把 `quant-research` 私有代码复制到公开仓库，也没有自动发布新的研究结果。公开页面只接收经过审查的派生数据，原始数据、缓存和运行产物继续留在仓库之外。
