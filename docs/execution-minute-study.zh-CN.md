# 分钟执行诊断

本次把历史分钟执行、资金约束和公司行动接入执行成本研究。它仍不能给出实盘容量，也不能识别自身订单造成的冲击。公开诊断按历史总市值选择40只沪深主板股票，与此前400只微盘股票、56个交易日的诊断属于不同样本。

已审查区间为2024年7月1日至12月31日（125个交易日）和2025年1月2日至12月31日（243个交易日），分别从现金开始，各有9组完整情景。2024全年不展示：原先183处无法解释的复权因子断点，重新观测后仍有21处未解决。2023分钟分区只有185／242个交易日，也不声称完成连续全年回测。

## 算法与数据

选股使用此前可用的日频记录、按公告日期判断的名称／ST资格、至少120个日历日的上市时间和已知停牌状态。收盘后形成目标，下一交易日北京时间09:32开始订单。重建的历史参考数据须通过来源收据检查，但这仍不是完整的历史修订版本数据库。

成交价格不复权，成交量按股、成交额按元。供应商分钟标签保守延迟一分钟才视为可用，并保留区间起点；整个区间必须晚于订单释放加延迟。集合竞价记录只作估值，不参与成交。历史成交额／成交量价格代理被限制在OHLC范围内。同股票同分钟的订单共享5%成交量上限，同时检查现金、先卖后买、T+1、100股整手和买卖方向的涨跌停触及条件。未成交订单会保留，遇新目标快照取消旧订单，或在固定期限到期。

30／120／330分钟窗口按实际经过时间计，包括午休；五批拆单时刻事先固定。比较每日调仓、每五交易日调仓及带缓冲的调仓。模型没有盘中排队、订单引起的价格变化、盘口补充或券商自适应拆单。

基础费用为买卖各1基点佣金、卖出另加5基点印花税，不设最低佣金。独立情景假设每笔母订单最低5元，跨部分成交累计收取一次。真实券商是否对每笔子订单收费仍待核对。毛收益情景保留执行约束，仅把费用设为零。

## 公司行动与停牌估值

权益登记日实际持仓决定现金和送转股权益；现金到付款日到账，股票到上市日才可卖出。未上市权益计入估值和目标持仓，但不能成交。现金分红采用税前金额，未模拟按股东持有期变化的税款。单独的公司公告修正与原始下载文件、公告PDF哈希绑定，不修改原始记录。只分配给债权人或重整投资人的股份，不计作原股东送转股。

确认全天停牌且没有分钟记录时，沿用此前观测的未复权价格，并处理期间已知普通公司行动。这些标记不能成交。2024下半年实际用了17个股票日，最长沿用7个日历日；2025年用了111个股票日，最长22天。未知停牌、盘中停牌和缺失持仓报价不会被静默补齐；持仓缺价会使净值失效。

## 结果怎么读

目标金额完成比例，把买卖母订单的目标数量和成交数量按各自到达参考价加权累计比较，不是期末剩余订单完成比例。到达价损耗合计有符号的成交价格变化、固定期限内未成交部分的机会成本和费用；缺失参考价的成本保留为空，不当成零。参考价可能来自原始观测或合成估值，因此该指标不能当作自身订单的因果冲击。

资金变化会改变可买数量、部分成交和后续组合路径。大资金情景净值更高，不代表容量更大或收益可以扩容。两个窗口长度不同、独立从现金开始，不能给年度收益排名。真实订单和报价记录仍是校准延迟、排队、收费和冲击模型的必要补充。

18组台账独立复算通过，共596,564笔成交、89,088笔订单、3,312行日度记录；检查覆盖现金、持仓、费用、公司权益、净值、损耗、参与率、时间因果、T+1和整手约束。网页只发布经审查的汇总字段，供应商原始记录、股票代码、详细订单和机器路径留在仓库外。

复现命令、来源公告与哈希约束见[英文方法记录](execution-minute-study.md#reproduce)。使用Python 3.12及以上，安装`formal`、`duckdb`依赖；两个窗口分别使用新输出目录。输入门槛失败时必须补证据，不通过平滑价格或补齐未知值绕过检查。已完成情景只有在输入、实现和输出哈希均一致时才能续用；公开汇总前仍须检查完整台账及停牌估值最长沿用时间。

原始结果保留实际运行代码哈希。合并版本仅补充已规范化日期的类型声明；独立检查去除恒等`typing.cast`和属性类型注释后的AST完全一致，公司行动契约未变。新版本不会自动续用旧哈希结果；复现须使用新输出目录。具体哈希见英文方法记录的实现来源部分。
