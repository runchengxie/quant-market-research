# 退市持仓的非交易估值情景

[English](execution-delist-valuation.md)

这项机制用于检查回测结论对退市资产估值假设的敏感性。估值事件保留法律股数，不产生现金或成交，并永久阻止该证券继续按A股规则交易。默认路径仍拒绝缺少依据的持仓估值。

源包绑定逐份来源哈希、规范事实、原生历史报价、研究窗口与实际交易日历。原价、复权因子、停牌记录和已建模公司行动不改动。减值进入账户后，后续目标数量会重新计算，不能只修补旧净值。

## 情景与时间边界

`full_impairment`、`impairment_then_observed`要求精确摘牌日期在摘牌日09:00前已知。中银绒业的该时间尚未证实，这两条严格情景目前仍拒绝运行。

另外两个可选情景明确使用“终止上市决定公开后的首个交易日09:00”作为全额减值起点。正源为2024年6月24日，美吉姆和中银为8月5日。部分减值早于法律摘牌日，这是保守假设，不是股票真实价值判断，也不表示当时已知道精确摘牌日期。

- `termination_decision_full_impairment`：此后持续零估值，原持股仍保留。
- `termination_decision_impairment_then_observed`：先全额减值，恢复转让后参考已可得的单来源历史报价重新估值。报价不恢复交易资格、不产生现金。

后续报价来自三只退市板块代码的183行未复权日线，仍缺独立历史价格与官方量额单位核验。美吉姆首日转让事实由2025年披露年报回溯支持，不能视为2024年实时可得证据。所有情景都保留`revision_safe=false`及相应限制。

报价可得时间假设为源日期次日09:00。估值生效时间映射到其后首个实际研究交易日09:00，并保留原可得时间。周末和假日不新增日账本，年末后才可得的报价不用于当年。若同一生效时间已有多个报价，只保留最新已知报价。未知价格不从未来反填。

## 运行与复核

在新的外部目录中只读复用经过哈希校验的准备输入，不复用原运行输出。先运行两个资金规模，九组矩阵仍保持不完整和未发布。

```bash
uv run --locked --extra formal --extra duckdb python scripts/run_execution_cost_minute.py \
  --run-prepared --output "$PREPARED_OUTPUT" \
  --valuation-source-packet "$SOURCE_PACKET" \
  --valuation-mode termination_decision_full_impairment \
  --scenario fees_1m --scenario fees_10m
```

对照情景在另一个新目录使用`termination_decision_impairment_then_observed`。政策、输入、来源或实现哈希改变时，不允许续用已完成结果。每组保留独立估值台账及政策回执，区分估值变化、公司权益和现金成交。

复核应独立重建现金、持股、费用、登记日权益、日净值及估值事件，并验证没有减值后成交、没有零价分钟行情或虚构卖出。完成日账本只表示该假设下账目闭合，不代表真实资产已变现、严格全年估值已解决或实盘容量已得到验证。退市板块的确权、集合竞价、费用与流动性需要另行建立处置模型。

原有18组公开结果保持不变。原2024严格运行及失败台账保留，新情景不替代它们。

## 本次试验范围

两种终止决定情景各运行100万元、1000万元，四组均覆盖242个交易日。独立重建资金、持股、公司权益、费用、估值变化和净值后，未发现账务错误或减值后的受影响证券成交。估值事件现金变化为零，法律持股保留。

这只验证已披露假设下的账目闭合。每种政策仍只有九组矩阵中的两组，完整矩阵未发布；单来源报价、修订版本和真实处置证据的限制保留。
