# 因子报警与全年执行探索

[English](execution-factor-resolution.md)

复权因子变化可以提醒我们检查有没有漏掉公司行动，但它本身不是现金或股票权益。本次加入可选的`--factor-evidence`，只对未复权价格账户的报警提供逐条来源证据；不提供证据时，原来的严格门槛仍然保留。

2024全年三个目标组合变体合计涉及109只股票，原始因子有183个未匹配公司行动的日期键。162个键在重新观测中相邻因子稳定；剩余21个键有独立原价、复权价格、参考价及全年事件查询交叉核对。另有25个变化对应已建模事件。原始因子不修改，11处舍入形状复现只作为辅助解释，不能代替逐条校验。

只把四天新数据拼回旧全年序列，会在6月24日等边界引入新报警。因此保留原因子，在原键上核验。所有适用原键的因子、前值和前交易日都必须匹配，即便把因子改成前值、使报警消失，也不能跳过绑定。非法因子、缺行、窗口或股票集合改变、哈希改变、未覆盖的新键都会拒绝。

证据文件绑定整个研究窗口、股票集合、日频清洗资产清单和分红来源哈希。剩余报警要求：独立原价OHLC及昨收一致；原始字符串计算的复权／原价比率精确恒定；日线覆盖完整；除权和分红查询覆盖整个窗口，且异常日没有观测到经济事件。已有独立来源若报告经济事件，不能因为主来源的新因子稳定就忽略。未知事件日期也不能当作“没有事件”。

真实分红、送转股仍由原公司行动模块按登记日实际持仓入账。回购差异化分红中，市场除权参考扣减与持有人实际到账现金可能不同，不能互相替换。证据校验不新增或删除任何权益。

运行先准备新输入，再仅选择`fees_1m`、`fees_10m`两个情景。此时仍是`complete=false`、`expected_scenarios=9`，不能当完整矩阵发布。独立复核资金、股数、应收权益、费用、估值和执行约束通过后，再运行默认九组；已完成结果只有输入、实现、配置及输出哈希均一致才能续用。完整命令见英文页。

该门槛通过，只允许继续做原价账户的探索性模拟，不代表供应商内部公式已查清，不代表完整修订版本PIT、实盘容量或因果冲击已得到验证。已公开的两个窗口结果保留原始运行来源；本次新结果需独立审查后才能发布。

## 本次试跑结果

新输入覆盖242个交易日、109只股票和6,216,836条分钟行情，25个公司行动已建模。100万元和1000万元两组均因持仓估值缺失而未完成，127个交易日无法形成完整净值。因此不发布全年收益，也不扩跑另外七组。

阻断涉及三只后来退市但仍有实际模拟持仓的股票：600321.SH于6月27日退市，002621.SZ于8月5日退市，000982.SZ于8月12日退市。逐日、分钟原始分区核查确认，停止交易后没有新行情；公告确认它们没有退市整理期。股份转入退市板块不等于持有人已经收到处置现金。
