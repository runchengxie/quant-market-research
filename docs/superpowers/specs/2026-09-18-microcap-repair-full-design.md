# 微盘股缺失价格修复审计设计

## 目标

为最小市值 400 股票组合建立可复现的缺失价格审计链路，同时保持严格口径为唯一主结果。任何补值结果只能作为明确标注的敏感性，不得静默进入主净值。

## 证据规则

- suspend_d 只在缺失持仓的确认下一交易日到下一次实际报价之间提供停牌证据。
- stock_st 只在同一窗口内提供 ST 事件证据。
- 退市证据来自 instruments 的 delist_date，并要求缺失窗口覆盖该日期。
- 没有直接证据的 gap 保持 unclassified_gap；不因没有报价而推断停牌、退市或可持有。
- 最后一个形成日没有下一交易日，不进入可分类的持仓收益审计。

## 输出口径

- strict: 所有选中股票都有下一交易日有效报价才计算收益；缺失日不进入 NAV。
- partial: 仅对有报价股票重新归一化，作为上界/暴露敏感性。
- carry: 仅把有证据的停牌缺失按 0 收益处理；其他缺失仍保持缺失，不填充。
- delist: 单独统计退市证据，不虚构清算价格。

## 交付物

- market-research report microcap-repair --config ... 可复现报告命令。
- CSV 分类明细、JSON 汇总、日级敏感性结果。
- 网页只发布带 exploration/not_for_primary_nav 标记的摘要，不替换严格主曲线。
- 文档明确显示数据源、生成时间、最后交易日、图表/数据的新鲜度和分类限制。
