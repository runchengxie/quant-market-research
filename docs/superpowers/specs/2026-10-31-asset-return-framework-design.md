# 长期资产回报研究设计

用户于 2026-10-31 确认：在现有专题内推进现金流与持有期、收益归因、跨资产分散、小微盘成本后研究，并核查补接现有 API 数据，细节由实施者决定。

## 目标与方案

采用扩展现有专题、共享研究输入契约的方案。另建独立年报网站会重复现有入口；只整理文献则无法形成可复算证据。现有 recovery、现金流价格／全收益比较继续使用，新建 `studies/asset_returns` 保存研究协议与入口。Python 研究代码仅提供本专题的描述性统计与归因，不建设通用交易或回测引擎。

## 研究范围

1. 月度价格／全收益对照、分红取现财富路径、固定金额与比例提款情景；含实际购买力、滚动持有收益、回撤与右删失回本记录。
2. 动态指数盈利／估值分解先明确会计恒等式；独立财务验证和固定成分比较仅在成分、股份及公司行动齐全后发布。
3. 同币种月度相关、滚动相关、权益下跌期的联合表现；固定权重再平衡研究使用平台或明确的月度理想化诊断，成本与实现限制可见。
4. 小微盘相对宽基的毛／成本后几何相对收益、负溢价等待与压力期表现，保留执行数据边界。
5. API 证据分为文档存在、账户可访问、样本返回、全期覆盖、语义验证和发布许可，不能相互替代。

## 数据与边界

原始数据接入归 quant-market-data-platform；研究只消费显式冻结输入。原始响应、运行收据、完整结果在 DATA_ROOT 下的新任务目录；不覆盖 current/latest，不改生产服务。现有账户只做有界只读探测，不购买权限、不发送 token 到未配置服务。报告数值作为外部对照，不作为独立复算结果。

月度输入保留币种、来源、价格／全收益类型和覆盖确认；缺失、重复、非有限值、日期断档阻断相关计算。分红取现须依赖单位份额现金分配，不能把全收益减价格的差额伪称到账现金。观察历史与当时可得输入分开，修订不安全数据不能宣称严格样本外。

## 验收与发布

先完成输入核查与可运行研究计算、财务边界测试，再运行实际可用资产，逐方向记录真实完成度与缺口。网页沿用现有现金流／估值／流动性入口，英文默认、中文可切换；仅发布审查通过的派生汇总。缺少必要输入的研究保留阻断状态和补数方案。Python 全套测试、Ruff、网页测试／构建／静态校验按实际变更运行；经 PR 必需检查后合并。
