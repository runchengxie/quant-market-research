# Interactive research reading and plain-language review

The owner requests richer interactive charts and a whole-site readability review. Existing authorization delegates implementation details. Preserve research results, sources, technical identifiers and evidence limits. Use the site's Astro/ECharts stack and locale catalogs.

## Design

Add linked, question-led charts to the recent asset-return sections. Cover return components and ten-year loss frequency, endpoint sensitivity, allocation return/risk, relative recovery, resampling ranges, spending, stress, publication periods and ETF proxy costs. Every chart uses already reviewed public aggregates. Do not invent distributions or individual observations from summary data. Repeated bar charts are fine when they answer comparable questions. Ranges retain their conditional resampling meaning; no future probability or causal claim is added.

Use native controls with keyboard support, localized labels/tooltips, theme-aware colors and responsive containers. Render charts lazily. Update linked tables and accessible text from the same selected rows; keep full tables available in disclosures. Static/no-JavaScript rendering keeps evidence tables open. Closing tables after a chart loads must not remove sources or sample limits. Preserve existing anchors and URL/locale behavior.

Inventory all public routes, locale catalogs and registered public documents. Review Chinese explanation strings and published Chinese Markdown while preserving lookup keys, source quotations, code fences, formulas, file names and identifiers. Lead with subject/action and the supported judgment. Keep material limits next to results. Replace rhetorical reversals, canned phrases and jargon; split overloaded sentences. Use Chinese punctuation in Chinese prose, including full-width parentheses. Technical syntax and English prose keep their own punctuation. Show exact audit coverage and remaining review items; do not claim universal simplicity from a regex count.

The primary overview becomes shorter through progressive disclosure. Source and calculation records remain inspectable. Research JSON/hash locks and statistical calculations stay unchanged.

## Verification

Test chart-data selection, units, denominators, range endpoints, missingness and links to controls before UI implementation. Test the prose scanner on lookup keys, templates, code and Markdown. Build and scan all generated public routes, then inspect representative pages in both locales, light/dark themes, narrow/wide screens and no-JavaScript mode. Preserve exact-data downloads. Independent final review checks source fidelity, scope and reader claims before required CI/merge/deployment.
