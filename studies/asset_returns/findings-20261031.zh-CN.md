# 长期资产回报：首轮复算与补数结果

[English](findings-20261031.md)

**已完成三组股票价格／全收益复算，以及股票、黄金、国债的月度分散比较。** 独立盈利验证和真实分红提款账户还不能发布结论；所需的历史版本和现金权益账本没有因 API 返回数据而自动补齐。

观察截至 2025-12-31，数据获取于 2026-10-31。本轮为事后描述性研究，包含指数发布前的回溯历史，不是当时可投资的账户或严格样本外实验。原始响应由数据平台任务目录保留；研究输入和完整结果在研究数据根目录下 `tasks/asset-returns-20261031/`。准备代码修订为 `81e5e4f`，计算修订为 `e718b5b`，每次结果另记录计算文件哈希和输入哈希。

## 1. 收益复算：大部分接近报告，一处差异需要保留

共同区间为 2004-12-31 至 2025-12-31，共 253 个月末水平、252 个月收益。

| 指数 | 价格年化 | 全收益年化 | 几何分配差异 |
| --- | ---: | ---: | ---: |
| 中证全指 | 8.84% | 10.40% | 1.43% |
| 沪深300 | 7.57% | 9.58% | 1.87% |
| 中证1000 | 10.14% | 10.87% | 0.67% |

几何差异为 `(1+全收益年化)/(1+价格年化)-1`，包含指数再投资机制，不是投资者实际到账现金，也不能与价格年化直接相加。

报告的沪深300全收益为 9.71%。报告另行估算并修正了 2005 年股息再投资；本轮直接保留 TuShare 的 H00300.CSI 序列，未套用这项修正。若仅将初年财富乘以报告使用的 1.026，21 年全收益年化约变为 9.71%。这说明修正足以在数值上解释差异，但没有独立认证报告的历史分红估算，不能把这次对照称为完全复现。[报告估算说明](https://youzhiyouxing.cn/sbbi2025/estimated-data/)

## 2. 持有十年仍可能损失购买力

按每个月末开始、持有完整 120 个月，各有 133 个已完成的重叠窗口；另有 120 个开始时点观察不足十年，不进入亏损比例。

| 全收益指数 | 名义亏损窗口 | 购买力亏损窗口 | 最差名义年化 |
| --- | ---: | ---: | ---: |
| 中证全指 | 3/133（2.26%） | 17/133（12.78%） | -2.29% |
| 沪深300 | 7/133（5.26%） | 17/133（12.78%） | -1.99% |
| 中证1000 | 11/133（8.27%） | 22/133（16.54%） | -6.59% |

这些是历史窗口频率，不是未来亏损概率。相邻窗口高度重叠，不能按 133 个独立样本计算置信度。购买力使用全国 CPI 已四舍五入环比的连乘近似值；不等同于年平均 CPI 口径。月末采样可能漏掉月内触及的回本和更深回撤。未回本记录单独保留，不能只统计成功回本者。

## 3. 分散在下跌时有帮助，但并非每次都有

国债财富数据从 2007 年起返回，本轮不估算更早历史。三资产严格共同区间为 2007-01-31 至 2025-12-31，共 227 个月收益：

| 月度指标 | 黄金 Au99.99 | 7—10 年国债财富指数 |
| --- | ---: | ---: |
| 与中证全指全收益的相关性 | 0.125 | -0.240 |
| A股下跌的 101 个月中，本资产上涨比例 | 58.42% | 73.27% |
| 这些月份的平均收益 | 0.54% | 0.48% |
| 这些月份本资产最差收益 | -14.92% | -2.21% |

与报告年度相关矩阵不同，本轮使用月度数据且起点不同；不能把数值差异解释为谁算错了。

三资产等权、理想化月末同时再平衡的毛年化为 8.03%，月末观察最大回撤为 -32.19%。再假设年度财富拖累 50／100 基点，年化分别为 7.49%／6.95%。这些是固定假设的敏感性，未校准交易成本，也不是可执行账户业绩；黄金使用现货价格，未加入保管、交割和投资工具费用。没有依据历史结果优化权重。

## 4. 小盘优势有多大，会被多少成本侵蚀

中证1000相对沪深300未修正全收益的几何相对年化为 1.18%，相对财富最大回撤为 -61.40%。小盘最终跑赢，并不意味着持有期间一直领先。

| 只施加于小盘的假设年度财富拖累 | 相对年化 |
| --- | ---: |
| 0 | 1.18% |
| 50 基点 | 0.68% |
| 100 基点 | 0.17% |
| 200 基点 | -0.84% |

这不是双方成本均已计入的净策略比较，也没有把拖累称为实测交易费用。中证1000是小盘指数，不能替代微盘组合或证明微盘 alpha。既有交易成本、容量和退市退出证据仍是执行研究的权威入口。

## 5. 哪些数据已经补到，哪些仍有障碍

| 数据路线 | 实际核查结果 | 可支持什么／仍缺什么 |
| --- | --- | --- |
| TuShare `index_daily` | 六条价格／全收益序列成功返回；每条 253 个共同月末端点通过日历核对 | 可做月度总回报对照；部分日频缺口不影响本轮端点，但没有认证全部日频完整性 |
| `cn_cpi` | 253 个月的全国环比均有值 | 可构造近似购买力水平；原始发布版本与精确定基指数未认证 |
| `sge_daily` | Au99.99 分段历史返回；253 个端点核对通过 | 可做人民币黄金价格比较；不能当作扣费黄金ETF收益 |
| `dividend` | 长江电力样本返回 54 条，含方案进度、登记／除息／支付等日期 | 需筛选实施方案、去重并衔接股份账本；54 条不等于 54 次实际派息 |
| `index_weight` | 2025-01 沪深300返回 300 条月度权重 | 只是单月样本，不证明21年成分齐备、日度权重或公告可得时间完整 |
| `fx_daily` | USDCNH.FXCM 2025-10 样本返回 26 条 | 是离岸人民币及特定交易商报价；还需区分 CNY/CNH、GMT 日期、买卖价与估值时刻，不直接升级六市场研究 |
| `yc_cb` | 返回 40203；官方文档要求独立权限 | 此路线受限，不能把收益率曲线当作债券总回报 |
| 中债公开查询／AKShare 对应路线 | 7—10年国债财富、净价各 4,954 条；综合指数久期 6,208 条 | 可替代性补数；本轮仅财富序列进入组合，综合指数久期不冒充国债指数久期 |
| `index_basic` | 返回 8,000 条，触及上限 | 只用于已返回代码的名称对照，不宣称是完整指数目录 |

账户可访问、历史完整、经济口径正确和可再分发是不同的检查。本轮只发布派生汇总，不发布原始报价、财报或供应商响应；批量和商业再分发许可没有由接口成功自动确认。

## 6. 尚未完成与明确的补证条件

- **盈利归因：** 已有恒等式核对代码，尚未发布盈利因果解释。需要独立财报口径、股份变化、历史成分／权重及修订版本；现有估值研究的 `revision_safe=false` 不能在这里改名为严格点时数据。
- **分红与提款：** 月度假设情景已实现、通过测试，尚未运行实际分红提款账户。需要除息权利与到账时点的份额账本；目前不从全收益与价格差额伪造现金。
- **债券收益来源：** 财富和净价已留存，但其差异并不直接等于纯票息；需处理应计利息、再投资及指数调整，匹配同一指数久期和收益率再做利率情景。
- **跨市场配置：** 尚未补齐海外ETF分配与同步汇率；本轮只发布人民币境内三资产比较。
- **微盘实测净收益：** 沿用既有执行成本研究的验证边界；本轮成本表属于小盘指数敏感性，不能升级为微盘实盘结论。
