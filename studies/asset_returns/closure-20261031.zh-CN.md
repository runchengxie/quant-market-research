# 证据核查与后续更新

ETF 的早期正收益差得到部分独立支持；缺失利润主要与原始成员退市有关，但现有 API 仍不能补齐固定成分盈利归因。更新校验和前瞻协议已实现，实际前瞻观察尚未准入。

## ETF：把大额差异与小额不一致分开

512100 的 API 月末复权净值给出：2018年 −35.4737%、2019年 +34.5458%、2020年 +31.3629%。基金管理人[2020年年度报告](https://pdf.dfcfw.com/pdf/H2_AN202103311479191748_1.pdf)第3.1节披露对应 −35.49%、+34.60%、+31.36%。前两年分别相差约1.63和−5.42个基点，未通过四舍五入到百分数小数点后两位的严格核验；2020年通过。差异原因仍待确认，不能将未通过核验写成完全一致。

2020年 API 的中证1000全收益参考为20.4537%，基金净值为31.3629%。年报第3.2节披露的价格指数基准为19.39%，不能与全收益参考混用。第4.4节列出新股、申赎权重偏差、停牌及调仓等因素；这些是管理人解释，尚无金额桥接，不能量化归因，更不能直接外推为持续超额收益。

完整年度对账从2018年开始：初始输入始于2017年1月，缺少2016年12月基点，不能把2017年的11个月当作完整年度。旧版本总区间结果保留，本轮没有静默改写历史净值。

## 固定成分：利润缺口不是零利润

按2015年12月成分追踪FY2025利润，沪深300缺8家，中证1000缺36家。2026年10月31日UTC／11月1日北京时间观察到的 TuShare `stock_basic` 显式字段结果：

| 初始成分 | 截至2025年底退市 | 2025年底后退市 | 当前状态标为上市但缺利润 |
| --- | ---: | ---: | ---: |
| 沪深300 | 8 | 0 | 0 |
| 中证1000 | 34 | 1 | 1 |

44个唯一代码的 `income(period=20251231, report_type=1)` 补查均未返回利润行；传输失败有保留记录并有限重试。这说明当前路径未取得数据，不证明公司没有利润或从未披露。状态来自本次供应商观察，不是截至2015年的时点资格。

其中002731.SZ的名称含“退”，但状态仍为L、退市日期为空，暂列供应商状态疑点；300379.SZ的退市日期字段为20260122。这些原始身份和名称记录保存在数据所有者任务目录，公开层只发布计数。合并、换股、退市后的公司延续关系与股东回收额尚未审计，不能以名称相近直接拼接继承者，也不能把退市等同于全损。

## 更新门槛

`validate_asset_update.py` 检查月份连续、日期唯一有序、数值有限且为正、列结构一致、币种／收益／成本口径一致，以及全部旧月份逐值不变。网站构建前另有 `validate-asset-release.mjs` 对三份公开派生数据和前瞻协议核对已审查哈希；变更必须同步更新审查清单。通过后只写带输入及代码SHA-256的独占回执，不改 `latest`、不自动发布。新历史修订必须另开有标识的研究运行，保留旧版本。该校验不替代交易日历末日确认、数据新鲜度和来源审查。

年度财富拖累与交易成本分别建模：假设财富100，静态年度拖累0.5%对应0.50；若买卖名义金额合计仅10，按50基点收取则为0.05。例子忽略收益变化，只说明计费基数不同，两种参数不能互换。基金内部费用已在净值中反映。

## 前瞻观察

[冻结协议](prospective-allocation-protocol.json)固定19个参考配置情形，无优化或优胜者筛选；最早候选为2026年12月，真实基线为2026年11月。现时状态为协议冻结、等待基线与入场回执，准入为false、完成窗口为0，收益未生成。

沿用 `register_research_window.py --study asset-allocation`；未来形成输入、迟到登记及过早历史形成日均拒绝。协议承诺本身不等于已完成登记。真实输入、官方日历和回执须在观察期前冻结，并取得绑定哈希的独立时间证据和准入审查。Git作者时间和本机时钟均不能证明提前登记。月度参考组合不代表可按已知收盘净值成交，十年指标须等待足够观察，缺失结果不填零。
