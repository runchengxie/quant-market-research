# 长期资产回报研究

[English](README.md)

本研究连接现有现金流、估值、小微盘、流动性与执行成本专题，区分历史观察、会计分解和假设情景。历史均值不直接用作未来预期收益。

## 已实现的研究入口

`python -m market_research.studies.asset_returns.run` 读取显式冻结的月度 CSV 和元数据，写入仓库外的新目录。命令、字段及 JSON 示例见英文协议。输出保留输入哈希与元数据哈希，不覆盖共享发布别名。

| 方向 | 计算与边界 |
| --- | --- |
| 收益来源 | 价格与全收益的几何分解；全收益／价格的差异不是到账现金股息率 |
| 持有期风险 | 1、3、5、10 年滚动收益，名义／实际亏损比例，未回本记录；重叠窗口并非独立样本 |
| 盈利与估值 | 指数价格、EPS 与 PE 的恒等式核对；反推 EPS 不构成独立财报验证 |
| 分散效果 | 月度、滚动相关及权益下跌月份联合表现；等权月度组合只是理想化诊断 |
| 相对收益 | 相对财富的几何年化、回撤与等待；不能全部解释为某一种风险补偿 |
| 现金与提款 | 留存现金、固定金额提款与按比例提款；缺口与卖出成本分别记录 |

## 必须保留的数据约束

月度日期连续，使用独立日历核对月末最后交易日的实际报价，不能拿更早的价格代替月末。缺失、重复、非有限或非正的资产水平会阻断计算。输入日历的完整性必须另行认证；程序只核对月末端点，不认证日内或全部日频路径。

CPI 使用价格水平；`chain_cpi` 从环比百分数连乘，并把首月设为基期，不能连乘同比。由四舍五入后的环比构造的购买力序列是近似值，不等同于官方长周期定基指数，也不必等于年平均通胀口径。汇率必须明确“每单位本币对应多少目标币”，金融资产先统一币种。

`coverage_verified` 是实施者有证据支持的声明，程序无法自行证明供应商历史真实完整。来源必须对应冻结输入、日期和哈希。原始响应归数据平台管理，网页仅展示审查后的派生汇总。

回本按月末观察，可能漏掉月内已经触及的回本；末日买入没有后续观察，也保留删失标记。复用回本模块时，字段 `trading_sessions` 在这里实际表示月度观察间隔，不应向读者翻译为日交易次数。

## 现金情景的适用范围

只有明确声明 `cash_timing=same_month_entitlement_and_payment` 才运行现金情景。单位价格与每份现金必须使用一致的拆股调整。模型假设当月初持有的份额在当月末同时获得分配权并收到现金，再提款；现金不计息、不再投资，先用现金、不足再卖出。固定金额与比例提款分别使用初始资金每年 4%／12 和每月 `1-0.96^(1/12)`，均是示例规则。初始买入费用、税收及真实到账延迟未计入。

因此，不能把只有除息日期的原始分红直接当作到账现金，也不能把价格与全收益之差填进现金列。真实提款账户仍须接入平台层的权益与到账账本。

## 还需补证的方向

动态指数分解先用于核对账面关系。独立盈利验证需要财务原始版本、成分权重、股份和公司行动；固定期初成分比较还须保留退市公司，不能用现有幸存成分倒推历史。

等权组合假设月末同时、无摩擦再平衡，0、50、100 基点年度财富拖累只是敏感性，不是已校准执行费率。小盘指数不能代表微盘策略；微盘净收益仍依赖既有成本、容量和退出研究。六市场 ETF 的股息覆盖、外汇时区与执行校准未完成前，不升级其研究结论。

参考：[中国大类资产投资2025年报](https://youzhiyouxing.cn/sbbi2025/)。本专题借鉴研究问题与对照口径，独立计算结果不会为了贴合报告而修改输入。
