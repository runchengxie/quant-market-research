# 市场状态：按可用时间读取的基线方法

[English](README.md)

证据阶段为合成方法验证，尚无 CSI1000 实证或未见样本收益结论。本文件不登记前瞻观察窗口。

`classify_market_states` 使用趋势、实现波动和截面离散度，阈值只在固定训练期估计一次。
每次决策读取严格在此前可见的最新特征；最新值缺失时不退回旧的完整值。
输出区分状态标签、空的概率字段和描述性标签切换；标签切换不是变点检验。
时区、输入可用性、训练范围和数据摘要均明确保留，时间戳本身不能证明历史 vintage。

真实研究启动前须冻结公式、窗口与基准，核对指数 price/TR 身份、交易日历、当时成分资格、
复权及截面覆盖率；报告状态持续性、切换率、缺失和未来尾部风险的样本及不确定性。
HMM 后续若加入，只能用当时 filtered 概率，不得以全样本平滑结果冒充当时识别。

拥挤先复核既有 owner 的代理及许可。只有收益证据时称为“收益隐含拥挤”，
真实持仓、交易与收益代理分开。公开研究不接收私有信号或组合规则。
后续的数据与启动条件见英文正文链接。
