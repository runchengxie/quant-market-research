# 现金流与微盘指数研究

本专题比较官方指数行情，并检查微盘规则重建的质量。结果属于市场证据，不能解释为飞书选股或实盘策略表现。报告读取共享数据，完整结果保存在仓库外。公开页面不包含机器路径、凭证或供应商原始文件。

回本等待研究已接入同一报告入口，指标定义见[回本等待与持有期风险](recovery-methodology.md)。长窗口配置见 `recovery.study.json`。配置中的数据路径是本机示例，运行前需改成可用的数据位置。

## 已实现的检查

- `index-study` 检查数据覆盖，在共同窗口内比较价格收益、CAGR 和最大回撤，并生成本地 HTML 报告。
- 现金流价格指数和税前全收益指数分开比较。
- 同一代码和日期出现冲突报价时停止计算。内部缺报价的指数不计算该区间收益。
- 报告对照外部交易日历。所有指数同时缺少某个交易日也会阻断比较。缺少日历时不生成表现比较。
- 阻断原因写入 HTML 和运行收据。失败重跑会清空相关净值文件，避免保留旧结果。
- 微盘 pandas 和 DuckDB 回放遇到已选持仓缺少次日报价时保留缺口，不把权重重新分配给其余股票，也不会生成完整净值。

## 仍需补充的验证

- 800 和国证的历史研究实现及结果仍位于私有 `quant-research`。本仓库复用公开行情，迁移算法前还需审查来源和依赖。
- A500、1000 当前用于官方行情对照，尚未完成逐期本地选股和持仓回放。A500 方案还要求关注每次样本数量调整比例，不能直接替换 800 股票池。
- 微盘缺价处理会停止输出完整净值。完整停牌估值、退市损失和公司行为账本仍需实现，旧版 400 股净值需要重新审核。
- 仍需核实历史 ST 状态、上市资格和形成时点。不得用 `next_day_valid` 等未来报价信息筛选形成日股票。
- 中证 2000 和国证 2000 用于小盘对照，成分范围不同于最小 400 股组合。Wind 和同花顺历史成分及收益口径仍需核验。
- 400 股日频序列与 3 股周频策略属于不同实验。周频策略留在 `quant-research`。

## 指数复刻的验收顺序

先核实官方成分和权重，再验证收益计算，然后依次比较本地现金流权重和本地成分。对账需报告共同日期、召回率、Jaccard、主动份额、日月收益相关性、年化跟踪误差和缺报价数量。

价格收益与税前全收益、零成本与成本后结果应分开列出。点时修订链不完整时，结论继续标记为研究状态。
