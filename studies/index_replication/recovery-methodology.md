# 回本等待与持有期风险

本研究使用通过交易日历和报价完整性检查的供应商指数。自建 400 股微盘净值尚未通过估值审计，不纳入本页的回本结果。原始行情、逐买入日明细和输入哈希保存在仓库外，网页只展示派生统计。

## 指标定义

- 完整水下期：从此前高点开始，到净值首次回到或超过该高点为止。自然日按日期相减，交易日按有效观测位置相减。回到原高点就算恢复，无需再创新高。
- 当前水下期：截至最后一个观测日仍未恢复的时期。`recovery_date` 为空，`censored` 为真。观测时长只是下界，不能作为完整恢复时长。
- 买入日回本等待：每个买入日之后，第一次收盘价不低于买入价的等待时间。这个指标只记录第一次回本，不代表之后不会再次亏损。样本最后一个买入日没有足够未来行情时，也作为未完成记录保留。
- 固定持有期亏损比例：分别检查买入日后 1、3、5、10 年或其后的首个交易日。超出样本范围的窗口标记为未成熟。亏损比例只用成熟窗口计算，并单列未成熟数量。
- 当前回本所需涨幅：用历史高点除以当前点位，再减一。例如净值跌去一半，需要上涨 100% 才能回到高点。

报告分别列出最长已完成等待和最长已观察等待。已完成时期的平均恢复时间不能用来预测未来。样本开始前的高点不可见，所有最长值只适用于报告所列区间。重复日期、空值、非正价格或非有限数值都会阻断计算。

现金流价格指数和供应商税前全收益指数分开比较。微盘指数沿用供应商点位，分红处理仍待核实。结果没有计入税费、通胀和机会成本。

## 运行方法

示例配置 `recovery.study.json` 使用相对占位路径。先复制到仓库外的本机配置，填入实际行情文件、交易日历和外部输出目录，再运行：

```bash
uv run market-research report index-study --study /path/to/local-recovery-study.json
```

结果文件包括 `recovery_summary.csv`、`recovery_episodes.csv`、`recovery_entries.csv`、`recovery_horizons.csv` 和 `recovery.html`。主 `receipt.json` 记录输入哈希和日历检查结果。输入验证失败时，回本文件会清空，页面展示阻断原因，旧净值不会保留。

主网页在 `#cashflow` 和 `#microcap` 专题内展示回本指标、指数选择、水下区间图、持有期统计和买入日等待明细。总览页只展示摘要、数据日期、研究进度和专题入口。网页读取同一份派生统计数据，不重新计算收益。

另外生成的 `recovery.json` 包含指数口径、样本区间、汇总统计、回本区间、持有期统计和最多 20 条最长等待记录。文件不含原始行情和本机路径。未成熟比例和未完成恢复日期保留为 JSON `null`。核验后才能复制到 `web/public/data/research/recovery.json` 发布。

## 首轮结果（2026-09-09）

现金流指数共同窗口为 2015-01-05 至 2026-09-04，微盘共同窗口为 2023-07-04 至 2026-08-14。

| 指数 | 最长已完成水下期（自然日） | 前高 | 回本日 |
|---|---:|---|---|
| 800 现金流价格指数 | 1073 | 2018-02-05 | 2021-01-13 |
| 1000 现金流价格指数 | 2285 | 2015-06-12 | 2021-09-13 |
| 同花顺微盘指数 | 308 | 2024-01-04 | 2024-11-07 |

800 价格指数中，已成熟的 1 年持有窗口有约 26.16% 亏损，5 年窗口约 1.35% 亏损。这些买入窗口高度重叠，不能解释为未来亏损概率。首次回本等待和固定持有期收益也是两个不同指标。

指数历史包含回溯构建数据。国证指数 2024 年规则修订前的历史身份需要单独说明，A500 发布日前的数据不能当作当时可投资的实盘表现。本研究只描述供应商指数的历史回撤和等待时间。A500、1000 本地成分复刻、公司行为账本和微盘可执行策略仍需独立验证。
